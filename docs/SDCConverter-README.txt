SDC Converter 1.4.0 — Windows x64
================================

SDCの値を読み取り、既存のNDUへ入力するツールです。
Python・pip・Visual Studio・Excelのインストールは不要です。

使い方
------
1. ZIPをフォルダーごと展開します。
2. SDCConverter.exe をダブルクリックします。
3. 参照SDCと入力NDUを選択します。
4. 「SDCの参照条件」で参照方向を選びます。有効抵抗土圧力は、さらに
   「応答変位法以外の場合」または「応答変位法の場合」を選びます。
   既定値は「（２）直角方向」「応答変位法以外の場合」です。
   参照方向は4項目すべて、応答変位法の区分は有効抵抗土圧力だけに適用します。
   参照方向を変えるとSDC列を読み直すため、KGInfoのチェックは解除されます。
5. 入力する項目を選び、対象のKGInfoをリストでチェックします。
   全KGInfoの部材範囲と長さ合計を表示します。最初は全件未選択です。
   SDCの地層厚合計と部材長合計を小数第3位（0.001 m）に四捨五入し、一致しない候補はチェックできません。
   SDC未選択や読込エラー時も候補は非活性になり、理由を表示します。
   チェックするとSDCモデル列が仮設定されます。列の選択欄で対応を確認・変更してください。
   「右押し」「左押し」は、チェックした杭のSDCモデル列を一括設定するボタンです。
   モデル図の左から順に、右押しは最大列から1列目へ、左押しは1列目から最大列へ設定します。
   杭数がSDC列数を超えた分には最大列を使用します。設定後も列を手動変更できます。
   右側に入力NDUのモデル図を表示し、選択KGの部材と部材番号が赤くなります。
   SDC/NDUを選び直すとチェックを解除します。同じファイルを外部編集したら「再読込」を押してください。
   SDC未選択でも全体のモデル図を確認できます。
   ホイールまたは＋／−で拡大縮小、ドラッグで移動、「全体表示」で元に戻ります。
   「対象部材番号」で番号を表示・非表示にできます。図は縦横別縮尺のXY表示です。
   赤色はKGの部材範囲を示します。計算条件の適否は「Excelをプレビュー」で確認してください。
6. 「Excelをプレビュー」を押すと、計算過程Excelタブに帳票を表示します。
   シートと表示位置を切り替え、倍率・縦横スクロールで計算結果と内訳を確認できます。
   セルを選ぶと数式または完全な値を表示します。青いリンクはダブルクリックで移動できます。
   この操作ではモデルもExcelも保存しません。設定変更後は再度プレビューしてください。
7. 保存先を確認し、「変換して保存」を押します。
   既定では「元の名前_変換済み.ndu」へ別名保存します。
8. 保存後、Windowsで関連付けたアプリでファイルを開きます。
   自動で開かない場合は「完了後、関連付けアプリで開く」を外してください。
9. 「計算過程をExcelに保存」は既定でオンです。モデルと同じフォルダーに
   モデル名.実行ID.計算過程.xlsx を作成します。「計算過程Excelを開く」で開けます。
   Excelの生成・アプリ内プレビューにMicrosoft Excelは不要です。

計算過程Excel
-------------
全項目を選択すると、水平地盤ばね・有効抵抗土圧・杭周面ばね・杭周面の支持力・
杭先端ばねの5シートになります。選択していない計算のシートは作成しません。
SDC原値と計算式は各主表に表示します。変換時の実入力との照合は内部で行います。
各主表には参照方向、有効抵抗土圧シートには参照方向と応答変位法区分も表示します。
液状化時SDCを使用した場合は、各主表と杭先端の勾配見出しにも「液状化時」を表示します。
元の値、区間の重なり、中点、補間・積分、丸め、NDUの入力欄、変更前後を記録します。
空欄と0を区別します。Excelで条件を編集してもNDUは更新されません。
保存時に帳票生成が失敗した場合はモデルを更新せず、理由を表示します。

_internalフォルダーには動作に必要なPythonとTcl/Tkが入っています。
EXEだけを取り出さず、展開したフォルダー全体を移動・配布してください。
関連付けアプリで開くには、NDUを扱うアプリが別途必要です。

対応する項目
------------
・水平地盤ばね
・有効抵抗土圧力
・杭周面ばね・支持力
・杭先端ばね・支持力

入力条件・計算方式
-----------------
・SDCの「N列目」形式と「奇数列・偶数列」形式の、橋軸方向・直角方向に対応します。
  奇数列・偶数列は杭配置条件の列数まで展開します。画面では実際の杭列番号を指定します。
  今町橋4Pの左基礎はKG1・2・3、右基礎はKG4・5・6です。
・有効抵抗土圧力は「応答変位法以外の場合」「応答変位法の場合」の両方に対応します。
  この区分は土圧だけに適用し、水平・周面・先端の参照表は切り替えません。
・従来の短期／地震時形式と、確認済みの液状化時形式に対応します。条件は選択方向内の
  既知見出しから自動判定し、複数項目の条件が一致しない場合は保存前に中止します。
  液状化時の先端K2・降伏点・終局点は、SDCに明示された0を空欄にせず数値0として入力します。
・SDCモデル列は各項目で実際に参照する列です。逆順や同一列の共用も可能です。
  左右のボタンは、チェックした杭のx座標順で列を設定します（KG番号順・チェック順には依存しません）。
  5列・5本なら右押しは5・4・3・2・1、左押しは1・2・3・4・5です。
  3列・5本なら従来どおり右押しは3・3・3・2・1、左押しは1・2・3・3・3です。
  ボタンを押した時点の選択杭だけを設定し、後からチェックを変えても自動では再設定しません。
・地層厚は選択方向の水平地盤ばね表から合計し、鉛直杭の部材長合計と比較します。
  両方の合計を小数第3位（0.001 m）に四捨五入します。各層・各部材は合計前に丸めません。
  長さ一致だけでは左右の基礎を区別できません。モデル図で対象の杭を確認してください。
・水平地盤ばね：層をまたぐ場合は長さ加重平均、整数への四捨五入。
・土圧：単一層内は両端で線形補間、層をまたぐ場合は積分平均を両端へ入力。
  最終値は小数第1位に四捨五入。画面で指定したSDC列を使い、変換時には列順を反転しません。
  押し方向のボタンは対象KGの列を設定します。SDCの形式はファイルの見出しから判別します。
・周面：既存画面方式。押込みK1を正負の全3勾配、Fyを正負の両制限値へ入力。
  節点の中点負担区間で積分し、Kは整数、Fは小数第1位に四捨五入します。
  引抜き表・第2勾配・終局点の個別反映や、1.2による補正は行いません。
・杭先端：SDCのK1/K2/Fy/Fuを転記。第3勾配はK2、負側制限値は空欄です。
  Ver.5.2.3の奇偶形式にある、鉛直ばねの勾配見出し省略・6値形式にも対応します。
・奇偶形式の同じ原値を使う杭列は、Excelでも原値を共有します。
  番号形式で値が同じでも元のCSV欄が異なる場合は、別の原値として扱います。
・CP932、改行、対象外データを保持します。支点追加時は件数と対応ケース行も同期します。
・傾斜杭、突出杭、杭長不一致、対象の重複・範囲支点、複数ケース等は
  既存スクリプトの条件に従いエラーにします。先端ばねへの周面抵抗の合成は非対応です。

保存とバックアップ
------------------
通常の別名保存では、入力ファイルや既存の保存先を上書きしません。
同じ保存先に再実行するときは、別の名前を指定してください。

「元ファイルを更新」を選ぶと、対象のNDUを更新します。
全項目の計算・検証後、同じフォルダーの一時ファイルに保存して内容を照合し、
日時付きバックアップを作成してから元ファイルを置き換えます。
確認後に入力が変更された場合や、ファイルがロックされている場合は中止します。
更新失敗時にも、作成済みバックアップが残ることがあります。

保存成功時は、同じフォルダーへ日時付き *.report.json を出力します。
入力パス、SHA-256、選択項目、計算根拠、保存先、バックアップ名を記録します。
報告書には案件名・パス・計算値が含まれるため、必要な相手にだけ渡してください。
バックアップから復元する場合は、対象アプリを閉じ、.bakファイルを別名コピーして
拡張子を元の .ndu に戻してください。

エラーになったら
----------------
・SDC/NDUが同じ対象モデルか、杭グループと列順が正しいか確認してください。
・保存先が既にある場合は別名を指定してください。
・保存できない場合は対象ファイルを使用中のアプリを閉じ、書込可能な場所を選んでください。
・「関連付けアプリで開けませんでした」と出た場合も、変換・保存自体は完了しています。
・予期しないエラーの詳細は %LOCALAPPDATA%\SDCConverter\error.log に記録します。

検証範囲
--------
既存の計算テスト、統合・保存障害テスト、展開したEXEでの起動と実データ変換を検証。
Input-JR/JRSNAP側での読込み・解析実行、別のクリーンPCでの動作確認は別途必要です。
本アプリが行うのは、既存仕様に基づく入力値の転記・計算とファイル形式の検証です。

BUILD-INFO.json はビルド情報、licenses は同梱ランタイム等のライセンスです。
