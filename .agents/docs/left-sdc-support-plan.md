## 1. 目的と今回の成果物

ユーザー指定の `tests/data/今町橋りょう4P/今町橋りょう4P(左).sdc` を、現在対応している右SDCと同じ画面・API・CLIで使用できるようにする。水平地盤ばね、有効抵抗土圧力、杭周面ばね・支持力、杭先端ばね・支持力の4項目と、計算記録JSON・計算過程Excelまでを対応範囲とする。

計画作成時の依頼は「まず現状と左SDCを把握し、修正プランを `.agents/docs` に書く」であった。その後「仕様書OKです。実装してください」と承認されたため、以下に従って実装する。調査に用いたSDC・NDU原本は保持する。

対応可否はファイル名の「左」「右」ではなく、選択した方向の各表の見出し・列構成から判断する。現在は橋軸／直角の両方向を選択でき、水平地盤ばねは短期を使用する。

## 2. 調査した入力と現在の状態

### 2.1 入力の識別

以下のSHA-256は調査時点のバイト列を識別するための記録であり、実装にハードコードする条件ではない。

| 入力 | SHA-256 |

| `tests/data/今町橋りょう4P/今町橋りょう4P(右).sdc` | `9b9aed2461b87acb5193c8eac79cf07b6d9824bdbd80e096416e197f324f64a7` |
| `tests/data/今町橋りょう4P/今町橋りょう4P(C方向･右押し→).ndu` | `31e9e85971d07ae1a0b21273f500b0d8d039184ecf9febb6db642fbfabfbd22a` |

左SDCはCP932、282行、12,826バイト、バージョン表記 `Ver.5.2.3`。`tests/data/今町橋りょう4P/今町橋りょう4P(左).sdc` とバイト単位で同一だった。右SDCも同じバージョン表記なので、バージョンだけで表形式を判別できない。

補助照合には `tests/data/今町橋りょう4P/今町橋りょう4P(C方向･右押し→).ndu` を使用した。同NDUのSHA-256は `703fd48092d3c4e0592ccb945538b03149f4cfa487d44b600f2a671fffe66a72`。

### 2.2 NDU側の左基礎

指定されたtest NDUには左右両基礎が存在する。「右押し」はモデルの押し方向であり、左基礎のKGを処理できないという意味ではない。

| KG | x座標 m | 部材範囲 | 杭頭節点 | 先端節点 | 杭長 m |
| --- | ---: | --- | ---: | ---: | ---: |
| 1 | -2.7 | 18～41 | 17 | 41 | 31.000 |
| 2 | 0 | 43～66 | 42 | 66 | 31.000 |
| 3 | 2.7 | 68～91 | 67 | 91 | 31.000 |

杭頭y=11.251 m、杭先端y=42.251 m。各杭24部材、25節点。節点番号と部材番号は一致しないので、引き続き `ElementInfo` の端節点を参照する。深さは各KGの杭頭からの相対値を使う。

右基礎はKG4/5/6、各31 m。現在の候補判定では右SDCに対してKG1～6がすべて長さ一致となる。長さ一致から基礎の左右を自動推定する機能は追加せず、対象KGと参照列を利用者が指定する。

### 2.3 現在停止する箇所

`kg_candidates.inspect_candidates()` はSDCの地層厚と選択可能列を得るため、`fill_jiban_shogen.parse_sdc()` を呼ぶ。水平ばねパーサーは `短期\(非線形\)-(\d+)列目` に一致する見出ししか認識せず、左SDCで例外となる。候補一覧が未確認になるため、GUIでは変換項目を変えてもこの入口を通過できない。

読み込み関数を個別実行しても、左SDCは4項目すべてで停止した。

| モジュール | 現在の制約 |
| --- | --- |
| `fill_jiban_shogen.py` | 水平表の `短期(非線形)-N列目` のみを抽出 |
| `fill_jiban_pressure.py` | 土圧表の各見出しが `N列目` であることを要求 |
| `fill_suppot_info.py` | d/e表の見出しが `1列目…N列目` の反復であることを要求。表の種類数を実杭列数と同一視 |
| `fill_pile_tip_suppot_info.py` | f/g表のN列目形式と、明示された短期第1・第2勾配見出しを要求 |
| `calculation_record.py` | 水平・土圧はN列目見出しを再検索。周面・先端は展開後の列数からCSV欄を算出 |

最後の計算記録処理も修正が必要。パーサー内で値だけを1/2/3列へ展開しても、元SDCのCSV欄位置が一致せず、Excel出力が失敗したり誤った出典を記録したりする。

## 3. 左SDCの内容

以下の行番号・CSV欄番号は1始まり。行番号は調査用の出典であり、読み込み実装では見出しで表を探す。

### 3.1 杭条件と地層

| 条件 | 左SDCの値 | 出典 |
| --- | --- | --- |
| 杭長／突出長／根入れ深さ | 31／0／1.3 m | 19行 |
| 直角方向の開始 | `（２）直角方向` | 153行 |
| 実杭列数 | 3 | 157行 |
| 奥行き本数 | 奇数列2本／偶数列1本 | 157行 |
| 1/β | 4.891 m | 157行 |
| 全層厚 | 3.300、1.300、2.900、2.600、0.600、9.500、10.800 m | 162～168行など |
| 累積境界 | 0、3.300、4.600、7.500、10.100、10.700、20.200、31.000 m | 全層厚の累積 |

22行の注記どおり、表の値は奥行き本数を考慮済み。展開時に2倍・3倍する処理を加えない。

### 3.2 水平地盤ばね（b表）

159行からの表で、161行の採用見出しは `短期(非線形)-奇数列` と `短期(非線形)-偶数列`。採用値は162～168行のCSV第7・8欄。

実杭列1/3には奇数列、第2列には偶数列を対応させる。第1層の展開値は `{1: 50638, 2: 25319, 3: 50638}` kN/m²。

### 3.3 有効抵抗土圧力（c表）

現行と同じ「応答変位法以外の場合」を使用する。173～174行が見出し、175～181行が採用データ。183行以降の応答変位法の表を混同しない。

| 元SDCの区分 | CSV欄（上側／下側） | 対応する実杭列 |
| --- | --- | --- |
| 1列目 | 3／4 | 1 |
| 2列目 | 5／6 | 2 |
| 3列目以降奇数列 | 7／8 | 3、5、7… |
| 4列目以降偶数列 | 9／10 | 4、6、8… |

このファイルの実杭列は3列だが、CSVには4区分が出力されている。4番目の区分は全層0。これを「4本目の杭が存在する」「GUIで4列目を選択できる」と解釈しない。区分の存在・数値は検証したうえで、実杭列数までを計算用に展開する。

第1層の実杭列1～3の値は、順に `(1788.9,2636.6)`、`(447.2,659.2)`、`(715.5,1054.7)` kN/m。

### 3.4 杭周面ばね・支持力（d/e表）

現行の `existing-screen` 方式を継続し、直角方向・押込み側の短期第1勾配K1と降伏点Fyを使う。

| 対象 | 見出し／データ行 | 奇数／偶数のCSV欄 |
| --- | --- | --- |
| d表の採用K1 | 198～199／200～206行 | 8／9 |
| d表の⊿l | 同上 | 7 |
| e表の採用Fy | 230～231／232～238行 | 4／5 |
| e表の⊿l | 同上 | 3 |

d表は1行11欄、e表は1行7欄。列の種類は2種類だが、実杭列は3列である。

押込み有効区間は深さ4.891～29.700 m。第3層の有効長は2.609 m、第7層は9.500 m。d表最終層の層厚9.500 mは先端除外後、e表最終層の層厚10.800 mは全層厚なので、引き続き両者を区別する。

第3層の奇数列はK1=30751 kN/m²、Fy=196.0 kN/m。偶数列はK1=15376、Fy=98.0。数値はSDC表示値をそのまま使い、奇数列値を2で割って偶数列を生成しない。

### 3.5 杭先端ばね・支持力（f/g表）

f表の鉛直ばねに、見出しとデータの欄数が一致しない形式がある。

```text
261: 長期,,短期
262: 奇数列,偶数列,奇数列,偶数列
263: 109024,54512,218048,109024,58945,29473
```

データは6欄で、次の対応が既存snap NDUの左基礎先端3支点と一致する。

| 採用量 | 奇数列 | 偶数列 | 原SDCの行／欄 |
| --- | ---: | ---: | --- |
| K1（短期第1勾配） | 218048 | 109024 | 263行／3・4欄 |
| K2（短期第2勾配） | 58945 | 29473 | 263行／5・6欄 |
| Fy（押込み降伏点） | 4778.4 | 2389.2 | 281行／1・2欄 |
| Fu（押込み終局点） | 11149.5 | 5574.8 | 281行／3・4欄 |

照合した既存支点は `SuppotInfo121`（節点41）、`SuppotInfo122`（節点66）、`SuppotInfo123`（節点91）。正負のK1/K2/K3、Fy/Fu、負側制限値の空欄を含め、既存の `TipValues.fields()` による10欄配置と一致した。

したがってこのパターンは、見出しが省略された「長期2欄＋短期第1勾配2欄＋短期第2勾配2欄」として限定対応する。見出しだけから一般的に推測できる規則ではなく、本実ファイルと既存NDUで裏付けられた互換処理として記録する。

水平・回転先端ばねは、長期／短期×奇数／偶数の4欄がすべて0。これらは鉛直ばねと異なる通常の2区分形式なので、6欄補完を適用しない。

## 4. 修正方針

### 4.1 実杭列と元SDCの欄を分ける

計算側は引き続き整数のSDC杭列番号を使用し、左SDCの2種類の値を実杭列数まで展開する。GUI、`--groups KG:列`、積分・平均・NDU書き込みの基本構造を維持する。

共通の列解決処理を `scripts/sdc_columns.py`（新規・仮称）に集約する。

- 実杭列数N: 選択した直角方向のa表から取得する。
- 番号形式: `N列目` を対応する整数へ変換する。
- 奇偶形式: 奇数の実杭列を「奇数列」、偶数を「偶数列」へ対応させる。
- 土圧形式: 第1/2列は専用欄、第3列以降は奇偶の後続区分へ対応させる。
- 各値に元SDCの行、CSV欄、元見出し、必要なら見出しの解釈種別を保持する。

共通モジュールから既存 `fill_*` モジュールはimportせず、循環参照を避ける。共通処理の例外は読み込み側で既存の `InputError` として利用者へ伝える。

奇偶形式は実杭列数がないと展開できないため、a表の欠落・重複・不正値をエラーにする。既存の番号形式では、項目別CLI・既存テストが必要な表だけを与える場合もあるため、a表を新たに一律必須にしない。a表が存在する場合は番号列との整合を検証する。

列番号形式と奇偶形式の混在、区分の重複・欠落など、意味を一意に決められない表は拒否する。右SDCの番号列の並び替えに対する既存の見出しベース読取は維持する。

### 4.2 パーサーの戻り値に出典を持たせる

既存の `Layer.values`、`PressureLayer.values`、周面の `Layer.values`、先端の `Profile.values` は実杭列番号をキーとする形を維持する。その隣に項目別の出典情報を追加する。

出典情報の例:

```text
水平:  実杭列3 → 値50638、SDC162行7欄、元見出し「短期(非線形)-奇数列」
土圧:  実杭列3 → 上下の値、SDC175行7/8欄、元見出し「3列目以降奇数列」
周面:  実杭列3 → K1=202行8欄、Fy=234行4欄
先端:  実杭列3 → K1=263行3欄、K2=263行5欄、Fy=281行1欄、Fu=281行3欄
```

実際の型名・格納単位は実装時に既存dataclassとの変更量を見て決める。ただし「計算記録側で見出しを再解釈しない」「展開後のNからCSV欄を再計算しない」を必須条件とする。既存の位置引数によるdataclass生成箇所も洗い出して追従させる。

### 4.3 各項目の変更

| 項目 | 修正内容 | 継続する計算 |
| --- | --- | --- |
| 水平 | 番号形式・奇偶形式の短期非線形見出しを解決し、列と出典を展開 | 層内値、層境界の長さ加重平均、最後の整数四捨五入 |
| 土圧 | 4区分を実杭列1～Nへ展開。上下欄の対応と数値を検証 | 層内線形補間、層境界の積分平均、小数1位四捨五入 |
| 周面 | 表の種類数2と実杭列数Nを分離し、d/e表を対応付け | 有効区間の算出、節点負担区間での積分、既存画面方式、最後の丸め |
| 先端 | 番号・奇偶形式と、限定した鉛直ばね見出し省略形式に対応 | K1/K2/Fy/Fuの採用、全10欄配置、負側制限値の空欄 |

先端の省略見出しを受け入れる条件は、対象が鉛直ばね表、上段が `長期,,短期`、下段が奇数／偶数の2回反復、データが正確に6欄、対応するg表が奇偶形式であること。今回確認した `Ver.5.2.3` の互換形式として分岐を明記し、通常の勾配見出しがある形式とは別に検証する。任意の見出し不足や余分なデータ列を許容しない。

上記互換形式の値は原ファイルを編集せずに解釈し、計算記録へ解釈種別と原見出しを残す。短期の2値しか存在せずK2が決まらない入力を、K1=K2などで補完しない。

### 4.4 列の割当とGUI/APIの互換性

左SDCに対する候補の列一覧は `(1, 2, 3)`、地層厚は31.000 mとする。GUIには奇偶という2択や、土圧表由来の余分な第4列を出さない。

現在の以下の仕様を維持する。

- 利用者が指定した列を全4項目で直接使用する。
- GUIは `push_direction="direct"` を渡し、土圧を再反転しない。
- 逆順指定・同一SDC列の共用を許可する。
- 押し方向ボタンはx座標順に、押す側から選択方向の最大列までを割り当て、超過分は最大列を共有する。
- 既存CLI/APIの `right` / `left` は互換用に残す。右押しの土圧反転には実杭列数Nを使う。左SDCの土圧区分数4を反転基準にしない。
- CLIの既定KG4/5/6を、ファイル名からKG1/2/3へ勝手に変更しない。左基礎のCLI例ではKGを明示する。

左基礎3本をGUIの右押しボタンで割り当てた場合は `1:3 2:2 3:1`。この左SDCでは水平・周面・先端の1列と3列が同じ奇数列値なので、土圧以外の採用値は順方向指定とも一致する。

エラーメッセージと説明文の「右基礎SDCを指定」は、対応する見出し形式、該当する表、問題の行・列を示す内容へ変更する。

### 4.5 JSON・計算過程Excel

`calculation_record.complete()` はパーサーが保持した出典を使い、水平／土圧の `index("N列目")` と、周面／先端の `ncols` によるCSV欄算出を置き換える。周面の除外層を含む全層一覧にも同じ出典を使う。

原値の識別キー `(処理, SDC行, CSV欄)` は維持する。

- 左SDCの第1/3列は同じ奇数列の原値セルを共有し、一方の原値編集が両列の計算に反映される。
- 右SDCの第1/3列は値が同じでも元CSV欄が違うので、引き続き独立する。
- 土圧の第1列と「3列目以降奇数列」は別の原値であり、同じ奇数番号という理由で共有しない。
- 共有する出典のラベルは元見出しに基づけ、どの実杭列から最後に参照されたかで書き換わらないようにする。

既存の `excel_report.build().src()` は出典キーによる共有に対応しているため、まず出典の正規化で対応し、帳票の計算式・レイアウト変更は必要なものに限定する。現在の主表5シート構成、固定実入力値との照合、プレビューとの同一セルモデルを維持する。今回の対応で補助シートを復活させない。

JSONは既存の行・欄・値を維持しつつ、列の展開方法や先端見出しの解釈種別を追加記録する。既存キーの意味を変える場合だけスキーマバージョン変更を検討し、無関係な形式変更を混ぜない。

## 6. 検証計画

### 6.1 読み込みと不正入力

- 実左SDCの4パーサーが成功し、全項目の実杭列が1/2/3、地層厚が31 mになる。
- 既存右SDCの値・列順・出典CSV欄が変わらない。
- 奇偶形式の合成入力で実杭列数1/2/3/4/5を検証する。第5列は水平・周面・先端では奇数値、土圧では「3列目以降奇数列」を参照する。
- 土圧の4区分と実杭列数を混同しない。第4列以降偶数の値を非0にした合成入力で、第4列が正しく選択されることも確認する。
- 奇数／偶数の欠落・重複、番号形式との曖昧な混在、実杭列数欠落・不正、上下見出し逆転、表幅不一致、負値、NaN/Infinityを拒否する。
- 橋軸方向にも類似表がある実ファイルで、直角方向だけを採用する。
- 先端の明示勾配形式と、今回の6値・省略見出し形式を受理する。4値しかない鉛直表、5/7値、未知の見出し省略は拒否する。
- 周面の第7層9.500/10.800 mの区別、1/β=4.891 m、有効長2.609 m・9.500 mを検証する。

### 6.2 独立した期待値

元SDCの欄と算式から期待値を固定し、修正後パーサー同士の比較だけで正しさを判断しない。

| 検証点 | 条件と期待値 |
| --- | --- |
| 水平・第1部材 | 順方向 `1:1 2:2 3:3` で部材18/43/68が50638/25319/50638 |
| 水平・層境界 | 部材20は深さ2.600～3.900 m。`(50638×0.700 + 267659×0.600)/1.300` を最後に整数へ丸め150802 |
| 土圧・右押し相当 | `direct`、`1:3 2:2 3:1` で部材18は715.5/849.1、部材43は447.2/530.7、部材68は1788.9/2122.8 |
| 周面・上端除外境界 | 節点21の負担区間4.550～5.850 mのうち有効長0.959 m。K=`30751×0.959=29490.209→29490`、F=`196.0×0.959=187.9640→188.0` |
| 周面・通常区間 | 節点22、有効長1.300 m。K=39976.300→39976、F=254.8000→254.8 |
| 先端・奇数列 | 節点41/91のK1=218048、K2=58945、Fy=4778.4、Fu=11149.5 |
| 先端・偶数列 | 節点66のK1=109024、K2=29473、Fy=2389.2、Fu=5574.8 |

周面の上記値は順方向指定。右押し相当の逆順指定でも両端は同じ奇数値を使う。NDUでは既存の数値書式により188.0を `188` と出力してよい。

旧snap NDUの部材68の土圧上端は1788.8だが、今回のSDC表示値は1788.9。旧NDU全体を無条件に正解とせず、表示値・現在の補間と丸めを期待値にする。旧NDUは先端の欄対応など、照合した範囲の証拠として使う。
