# 水平地盤ばね Excel帳票の修正プラン

作成日: 2026-09-17  
状態: 承認済みの修正仕様。2026-09-17に実装・検証を完了。結果は [Excel帳票実装記録](excel-report-implementation.md) を参照。以下は承認時の調査・計画を保存したもの。

## 1. 依頼と対象

Excel変換で生成する「水平地盤ばね」シートを、次の見本の表に合わせる。

- 見本: `test/今町橋りょう4P(C方向･右押し→)_変換済み.ndu.計算過程.見本xlsx.xlsx`
- 対象シート: `水平地盤ばね`
- 見本のSHA-256: `cc5011841554ec8f441a3de88c3f71b26e05bc3afadfef9d7a143a731360c58a`
- 今回の成果物: 本仕様書のみ。見本・入力モデルの上書き、変換処理の修正、配布EXEの再作成は行わない。

見本ブックには「有効抵抗土圧 (2)」もあるが、そのシートの追加・変更は今回の対象ではない。同名の見本が `snap` にも存在し、調査時のハッシュは同一だった。今後の基準はユーザー指定の `test` 側とする。

本書は [Excel帳票実装記録](excel-report-implementation.md) を前提とする部分改訂案である。[初期仕様書](sdc-excel-calculation-report-spec.md) にある「Excel機能未実装」は当時の調査状態であり、現在はExcel出力・GUIプレビューとも実装済み。

## 2. 現状

### 2.1 処理経路

| 段階 | 現行ファイル・主な関数 | 担当 |
| --- | --- | --- |
| 計算 | `scripts/fill_jiban_shogen.py` の `parse_sdc` / `collect_members` / `find_overlaps` / `select_value` | SDC原値、NDU部材座標、層との重なり、採用値の算定 |
| 変換計画 | `scripts/portable_converter.py` の `prepare` | 入力バイト列を保持し、変換結果と各部材の計算記録をメモリ上で作成 |
| 共通記録 | `scripts/calculation_record.py` の `complete` | 部材幾何、層境界、SDC出典、変換時の固定実入力を補完 |
| 帳票 | `scripts/excel_report.py` の `build` / `ReportBook.to_xlsx` | 共通セルモデル、数式AST、キャッシュ評価、XlsxWriterによる保存 |
| GUI | `scripts/excel_preview.py` の `ExcelPreview` | 同じセルモデルをTk Canvasに表示 |
| 個別CLI | `scripts/excel_cli.py` | `--excel-report` 指定時も共通の記録・帳票を利用 |

GUIプレビューは完成済みxlsxを読み込む方式ではない。帳票モデルを変更するとExcelとGUIの両方へ影響する。

### 2.2 現在の「水平地盤ばね」シート

12列幅のシートに、次の表を縦に並べている。

1. 共通タイトル、実行状態・日時、色と固定値の説明。
2. 「部材別の結果」: KG、列、部材、方法、丸め前、再計算値、実入力、差。
3. 「部材の幾何」: 端節点、上下端深さ、部材長。
4. 「層別の重なりと加重和」: 層境界、重なり長、原値、原値×長さ。
5. 「Python Decimalの丸め前文字列」。

`test` の右SDC・右押しNDUを現行 `prepare()` に渡したところ、水平ばねは72部材・90重なり区間。見出しの再掲を含め358行、水平改ページ指定21か所だった。この数は今回の入力での結果であり、一般仕様の固定値ではない。

### 2.3 維持すべき計算・保存仕様

- SDCの「（２）直角方向 → b）水平地盤ばね値 → 短期(非線形)-N列目」を採用する。
- 既定の対応は `KG4:1列目 / KG5:2列目 / KG6:3列目`。任意の選択KG・列対応にも従う。
- 部材区間は `ElementInfo` の両端節点と `JointXY` から取得する。節点番号を部材番号から推測しない。
- 単一層は原値をそのまま採用する。複数層は既定で重なり長による加重平均を最後に整数へ `ROUND_HALF_UP`。
- `midpoint / skip / error` の既存指定も維持する。
- モデルへの反映先は `JibanShogenInfo<部材番号>` の第2欄。単位は `kN/m²` のまま。
- 数式による再計算値と、変換時にモデルへ設定した固定実入力を区別する。数式を編集しても固定実入力は変化しない。
- 数式ASTからExcel式と計算キャッシュを作り、保存前に最終値と実入力を照合する。保存後のZIP/XML照合も維持する。
- 入力保護、既存ファイルとの競合確認、バックアップ、モデル・JSON・Excelの公開手順は変更しない。

この見本には実行日時・色の凡例・旧4表はなく、白地に細い罫線、MS 明朝10ptで構成されている。

### 3.2 7列の意味

以下は左ブロック。中・右はそれぞれ7列・14列ずらした同じ構成。

| 列 | 見出し・役割 | 記載ルール |
| --- | --- | --- |
| A | 層番号 | その地層の最初の行だけ表示 |
| B | 層厚 (m) | 地層全体の厚さを最初の行だけ表示 |
| C | 水平地盤反力係数 Kh (kN/m²) | 各重なり行に、その層・杭列の原値を表示 |
| D | 部材長 (m) | 部材の全長を、その部材の最初の行だけ表示 |
| E | 部材長の内訳 | 複数層をまたぐ場合、各層との重なり長を各行に表示。単一層は空欄 |
| F | 部材番号 | 部材の最初の行だけ表示 |
| G | 各部材の水平ばね定数 Kh (kN/m²) | 部材の最初の行だけ計算式を表示 |

見出しの「部材長」はD2:E2の結合セル。実際の結合は `D2:E2 / K2:L2 / R2:S2` の3か所のみ。**データの層欄・部材欄は縦結合されていない。** 値を最初の行に置き、空欄と罫線の省略でまとまりを表している。

### 3.3 行展開と数式の具体例

| 部材 | 見本位置 | 重なり長 (m) | 見本の数式 | 保存済みの計算値 | 整数表示・現行採用値 |
| --- | --- | --- | --- | --- | --- |
| 98 | 3行 | 単一層、部材長1.3 | `G3=C3` | 58812 | 58,812 |
| 99 | 4～5行 | 0.2 + 1.1 | `G4=(C4*E4+C5*E5)/D4` | 272085.92307692312 | 272,086 |
| 104 | 12～14行 | 0.5 + 0.6 + 0.2 | `G12=(C12*E12+C13*E13+C14*E14)/D12` | 363439.69230769225 | 363,440 |
| 121 | 32行 | 単一層、部材長1.1 | `G32=C32` ※ | 193733 | 193,733 |
| 124 | 4～5行、中ブロック | 0.2 + 1.1 | `N4=(J4*L4+J5*L5)/K4` | 181390.6153846154 | 181,391 |

※ Excelファイル内で共有数式として格納された式は、セル位置に応じた式として記載。

見本のG/N/U列は `ROUND` のない丸め前の式で、整数表示書式によって整数に見えている。これを「セル内の数値も整数」と解釈しない。

各KGの複数層部材は5件、うち1件は3層にまたがる。3層の例を2層専用の式へ単純化してはいけない。層厚の合計と部材長の合計は、見本の各杭とも31.000 m。

今回、見本の全72結果セルの保存済み数値を現行の丸め前記録と比較し、差はすべて `1e-9` 以下だった。整数化した結果も全72件が現行採用値と一致した。**計算方式を変更する必要はなく、主な変更は表現・配置である。**

### 3.4 書式・印刷設定の観測値

- 1ブロックの列幅: `8.75, 8.75, 16.875, 9.625, 9.625, 9.625, 20.75`。この値はxlsxに保存された幅であり、生成ライブラリへの指定値と表示結果は実機で照合する。
- 行高: タイトル24pt、見出し48.75pt、明細・Σ21.75pt。既定行高23.1pt。
- 長さ: 小数3桁、右寄せ。Kh: 桁区切り整数表示、中央寄せ。層・部材番号: 中央寄せ。
- A/Bは地層境界に、D/F/Gは部材境界に横罫線。Cは各行を区切る。DとEの間には内側縦罫線を入れない。
- 印刷: A4縦、範囲 `A1:U34`、G列とN列の後に手動縦改ページ。
- 余白: 左右0.7in、上下0.75in、ヘッダー・フッター0.3in。
- 枠固定なし。保存時の表示は改ページプレビュー、ズーム85%。
- 印刷タイトルが `$1:$34` になっている。これは観測値であり、長い一般データへそのまま適用する仕様にはしない。

セル構成・数値・罫線はXMLとレンダリング画像で確認済み。Microsoft Excelでの実際の印刷ページ数は本調査では未確認。

## 4. 修正方針

### 4.1 主表は見本と同じ配置にする

水平シート専用の組み立て処理を設け、共通タイトル4行と旧4表の生成をこのシートでは行わない。タイトル1行・見出し1行・明細・Σの構成とし、見本の入力では `A1:U34` を再現する。

KGごとに7列のブロックを作り、SDC杭列の順に左から並べる。3ブロックや部材98～171を固定値にせず、選択数Nに対して7×N列を用意する。例えば `5:2` のみならA:Gへ1ブロックを出力する。

ブロックとKG/SDC列の対応は「入力根拠」の実行設定に残し、GUIの表示位置にも `KG5 / SDC2列目` などの移動先を設ける。主表の見出し・列を増やさない。

### 4.2 1行を「部材と地層の重なり」にする

1. 各KGの部材を上端深さ順に並べる。
2. 部材の正の長さを持つ `pieces` を深さ順に展開する。1区間につき1行。
3. 層番号が切り替わった行でのみA/Bを記入する。Bは `layer_bottom_m - layer_top_m`。
4. Cは同じ層が続いても毎行、対応する「入力根拠」の原値セルを参照する。
5. 部材先頭行だけにD/F/Gを記入する。Eは複数層の場合だけ各区間長を記入する。
6. 層境界と部材境界を別々に管理し、各列の罫線を決定する。データの縦結合は追加しない。
7. Σ行は最大ブロック行数の次にそろえる。短いブロックの残りは空欄とし、余分なデータや計算式を埋めない。

層数、部材数、部材長、1部材が重なる層数、ブロック間の明細行数の違いに対応する。層境界ちょうどで接するだけの0長区間は行を作らない。

### 4.3 見本の数式と最終値の照合を両立する

- 単一層のG列はC列への参照式。
- 既定の複数層のG列は `Σ(C×E)/D` の丸め前の式。項数は区間数に合わせる。
- 主表は見本同様に整数表示とし、計算値そのものは丸めない。単一層の原値に小数がある入力でも、モデル値を整数へ変更しない。
- 部材長・重なり長は既存の幾何・層境界から計算し、原値の出典と数式による追跡可能性を維持する。元の十進精度を失わない座標演算の桁保持も引き継ぐ。
- Σ行はBとDをそれぞれ合計する。Eの重なり長をDの部材長合計へ重ねて足さない。

見本にない実入力・差・丸め前文字列を主表へ再追加せず、「入力根拠」の既存内容の**末尾**に水平ばね用の幾何・層境界・照合表を追加する案とする。

| 補足表 | 残す情報 |
| --- | --- |
| 地層・部材幾何 | KG/列、層番号、層上下端、部材番号、端節点、上下端深さ。主表の長さ式の参照元 |
| 水平ばねの照合 | KG/列、部材、方式、主表の丸め前値、採用再計算値、固定実入力、差、正確なDecimal文字列・保留理由 |

採用再計算値は、複数層加重平均なら主表値を `ROUND(...,0)`、単一層なら原値のまま。このセルを既存の `ReportBook.expected` の照合対象とし、丸め前の主表値を整数の実入力へ直接比較しない。差セルの警告表示も移す。

「変換結果」の固定実入力一覧は維持し、明細へのリンク先を新しい水平主表の部材先頭行・対応ブロックへ変更する。数式原値は引き続き「処理＋SDC行＋CSV欄」をキーにする。1列目と3列目が同値でも参照元を共有しない。

### 4.4 非既定方式と一般入力

| 条件 | 方針 |
| --- | --- |
| `midpoint` | 主表Gは中央深さの層の原値を採用。長さ内訳は表示する。方式と採用理由を補足表に明示し、加重平均として扱わない |
| `skip` | 主表Gは保持する現在値を表示し、保留であることをブロックの注記に示す。空欄は空欄。採用値検証の対象から除外する現行規則を維持 |
| `error` | 現行同様、複数層をまたぐ部材があれば変換計画をエラーにする |
| 水平ばね未選択 | 水平シートも水平用補足表も生成しない |
| 杭が層の途中で終わる | Bは地層厚、Dは部材全長なので両合計が異なり得る。機械的に一致を必須としない。各部材の重なり長合計＝部材長を検証する |

非既定方式では見本に必要最小限の方式注記を追加する。モデルの対応入力範囲を広げる作業は含めない。傾斜杭等の既存入力制約も維持する。

## 6. 印刷の修正案

主表は見本のA4縦・7列1ブロックを印刷の単位にする。画面上で3表が横に並んでいても、21列全体を1ページ幅に縮小しない。

- 7列ごとの手動縦改ページを設定する。見本入力では3ブロックをそれぞれ1ページに収めることを目標とする。
- 印刷範囲は実際の使用列とΣ後の空白行まで。見本入力はA1:U34。
- 印刷タイトルは見出しである1～2行を基本とする。見本の1～34行指定は全明細反復になるため、そのまま一般化しない。
- 余白・フォント・列幅・行高は見本を基準に、Excel実機で用紙内に収まる印刷倍率を確認する。画面表示倍率85%と印刷倍率は別物。
- 現行の「全列幅からA4横へ縮小」の計算は水平には適用しない。手動改ページと `FitToPages` の併用による改ページ無効化も避ける。
- 部材数が多い場合は縦に複数ページを許容する。部材の内訳は可能な限り分断せず、分断が必要な長い内訳には続きと対象部材を明示する。3層などの区間数に上限を設けない。

実機確認が必要なため、印刷倍率と最終ページ数は実装検証で確定する。見本の保存設定だけから実際に3ページと断定しない。

## 7. 実装順序と検証

1. 既存入力と現行出力値を基準に、見本の列・行・代表式・書式を受入条件として整理する。
2. 共通セルモデルへ必要最小限の範囲結合・書式・印刷・移動先設定を追加し、他シートの既定挙動を保つ。
3. 水平専用ビルダーと補足表を実装し、数式・固定実入力・内部リンクを結び直す。
4. GUIに可変列数・結合見出し・水平用書式・横移動を反映する。
5. 下表の検証と既存回帰テストを実施する。
6. Excel実機で再計算・表示・印刷を確認し、実装記録を更新する。

| 検証対象 | 受入条件 |
