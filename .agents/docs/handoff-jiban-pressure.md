## ユーザー確定事項

1. 右基礎の対象グループはKGInfo4・5・6、部材98～121・123～146・148～171、合計72部材。
2. `--groups 4:1 5:2 6:3` はモデル内の左からの杭列を指す。
3. 水平地盤ばね値はSDCの1・2・3列目。これに対し、**有効抵抗土圧力は右押しでSDCの3・2・1列目**。部材98の1162.9・1329.7が土圧表の3列目であること、右押し・左押しの既存NDUの配置を照合して確認した。
4. 有効抵抗土圧力は「直角方向 → c）有効抵抗土圧力 → 応答変位法以外の場合」の187～193行目（kN/m）を使う。応答変位法の199～205行目とは別。
5. 単一層内の部材は、層の上側・下側土圧を線形分布とし、部材の上下端位置で補間する。
6. 層境界をまたぐ部材は、**各層の分布を重なり区間で積分して部材長で割り、同じ平均値を部材の上下端へ入力する**。これはユーザーの明示回答。
7. 土圧は**上下端とも小数第1位へ四捨五入（ROUND_HALF_UP）**。途中で丸めず、最後の1回だけ丸める。これも明示回答済み。ばね値の整数丸めを土圧へ流用しない。

```text
層内補間: p(z) = p上 + (p下 − p上) × (z − 層上端) / 層厚
層境界をまたぐ平均: Σ[(p(ui) + p(vi)) / 2 × (vi − ui)] / 部材長
```

部材98の結果は **1162.9・1307.5**。既存NDUの上端1163には合わせず、SDCの表示値から計算する。

部材99は第1層0.200 mと第2層1.100 mにまたがり、積分平均は **1988.988343195266… → 1989.0**。上下端とも1989と保存する。質問文で一度示した「約1989.016」は概算誤りで、会話中に訂正済み。この値を再利用しない。

## 実装上の注意

- `fill_jiban_pressure.py` は同じフォルダーの `fill_jiban_shogen.py` に依存する。両方を保持する。
- CP932のSDCの杭列見出しは `,,1列目,,2列目,,3列目` と最後の空欄が省略される。パーサでは末尾の空ラベル1個だけを補い、上側・下側との対応を検証している。
- 幾何は鉛直杭、x一定、yが深い側へ増加するモデルに対応。層外への補外、部材の隙間・重なり、列不足はエラーとする。
- `--push-direction left` はモデル列と土圧列を同じ番号にする。右押しの逆順対応と区別する。
- `.agents/docs/snap-jiban-shogen-mapping.md` の対象外項目を今回仕様へのリンクに更新した。
- 今回の新規ファイル・変更はコミットしていない。`~$input.xlsx` はユーザーのExcel操作に伴う一時ファイルであり、この作業では触っていない。
