## 5. 改訂後の仕様案

### 5.1 シートと対象行

- シート名は「杭先端ばね」のまま。K/Fを別シートには分けない。
- `tip` は引き続き1工程。全工程7シート、tipのみ3シート、tip未選択では先端シート・先端補足を作らない。
- 選択した全KGについて、上表・下表に各1行を作る。先端節点を最大の節点番号で決めず、現行の幾何判定結果を使う。
- 行順は現行の `details.tip.nodes`、すなわち受け付けたKG指定順を維持する。上下2表と補足表で同じ対応にする。
- 例: `6:3 4:1` は現在も許容され、節点172→122の順になる。この順序を勝手にソートしない。
- KG番号・SDC列・支点項目は「入力根拠」に残す。主表A列は見本どおり節点番号とする。

### 5.2 3列表の配置

基準の3件では第4.1節の `A1:C14` を再現する。
主表の先頭に共通帳票の実行日時や説明行を挿入せず、既存の「変換結果」「入力根拠」に実行情報を保持する。

改ページの見出し再掲を除いた論理位置は次のとおり。nは選択した有効な先端節点件数（n≧1）。

| 内容 | 行（1始まり） | 列・内容 |
| --- | --- | --- |
| 上表題 | 1 | A: 杭先端のばね定数 |
| 上見出し | 2～3 | A縦結合「節点番号」、B2:C2横結合、B3 K1/C3 K2の見出し |
| 上データ | 4～n+3 | A:節点、B:K1、C:K2 |
| 空白 | n+4～n+5 | 2行 |
| 下表題 | n+6 | A: 先端支持力 |
| 下見出し | n+7～n+8 | A縦結合、B(n+7):C(n+7)横結合、降伏点/終局点 |
| 下データ | n+9～2n+8 | A:節点、B:Fy、C:Fu |

タイトル・単位・全角括弧等は第4.1節の見本表記を使う。合計行・KGごとの横ブロック・追加の係数欄は設けない。
3件以外を許容するため、6/9/14等の行番号、122/147/172、KG4～6を実装へ固定しない。

### 5.3 値・数式・表示精度

見本は数値直書きだが、新主表のK1/K2/Fy/Fuは現行の再計算機能を保つため**数式でSDC原値セルを直接参照**する。
原値のキーは `("tip", SDC行, CSV欄)`。値の一致をキーにして1列目と3列目をまとめない。

- B4相当 → K1原値、C4相当 → K2原値、下表B/C → Fy/Fu原値。
- 主表への `ROUND`、杭長等の乗算、K1からK2の流用、FyからFuの流用はしない。
- 3件時の独立した原値参照は12個。複数の表示箇所がある場合も同じ出典セルを参照する。
- 変換時の固定実入力は計算記録の `fields.after` から取得し、Excel原値編集で更新しない。
- 原値セル変更は該当SDC列・該当量の再計算値と差だけへ伝播する。Excel編集からNDUを更新する機能は追加しない。

主表の桁区切りはなし。基準入力はKを整数、Fy/Fuを小数1桁で見本どおり表示する。
小数を持つ別入力では原値の桁を隠さないよう、生成時の各量の十進精度に応じて表示桁を拡張する。
候補書式はKが `0` または `0.###` 等、Fが最低1桁の `0.0` または `0.0##` 等。
`#` の桁数は入力に応じて決め、3桁固定にはしない。末尾の空白指定は数値の意味を持たず、GUIと共通に扱える書式を使う。
Excel生成後に表示精度以上の値へ編集した場合も、セル値・数式バー・補足の照合で値を確認できること。

表示書式を計算丸めに使わない。Excelの数値表現で保持できない精度は現行の照合エラーと正確な十進文字列で扱い、
固定値との比較許容差を拡大して隠さない。対応する入力精度自体の拡張は今回の対象外。

### 5.4 「入力根拠」への移設と照合

既存の共通情報・SDC原値・SDC原行・NDU幾何原行を維持する。
先端専用の補足は、現在の水平・土圧・周面補足の後へまとめ、次の順序で追加する。
先端しか選んでいない場合も、同じ生成処理で共通情報の後へ追加する。

| 補足 | 項目・式・役割 |
| --- | --- |
| 先端の杭頭・最深節点と杭長 | KG、SDC列、杭頭節点、先端節点、x、杭頭y、先端y、座標差、SDC杭長、杭長差、支点項目、NDU行。座標差は既存の座標精度用ROUND、杭長差は座標差－SDC杭長 |
| 先端の採用照合 | 1節点×4量を縦に並べ、KG、列、節点、支点項目、量、単位、主表値、固定実入力、差を表示。主表値は主表参照、差は主表値－固定実入力。先端値の採用ROUNDは不要 |
| 先端のばね実入力 | 現行6欄K1+/K2+/K3+/K1−/K2−/K3−を固定値で保持 |
| 先端の制限値実入力 | 現行4欄F1+/F1−/F2+/F2−を固定値で保持。F1−/F2−は数式の空文字や0でなく空セル |
| 先端の正確な十進記録 | KG・節点・量・SDC原値の正確な文字列を保持。先端は追加丸めをしない旨を明記 |

先端補足で、SDC行・CSV欄と実入力の13フィールド中の位置を追跡できるようにする。
f/g表の直角方向・短期/地震時の見出し、杭長・配置条件の原行は既存の共通出典を利用する。
SDC杭長の原行は今回19行だが、この番号を前提とする新しい解析処理は追加しない。

`book.expected` の4n採用値検査を保持し、差4n個と杭長差n個を `checks` として表示する。

### 5.7 印刷

基準入力の目標は **上下2表をA4縦1ページ**に収めること。

多数の杭で縦に長くなる場合は、次の規則で先端表専用の行配置を生成する。

1. 上表全件、空白2行、下表全件の順序を保つ。横にKGブロックを増やさない。
2. 用紙の印刷可能高さと倍率・実行高から収容行数を算定し、節点行の間で改ページする。
3. ページ先頭に現在の表のタイトルと2段見出しを再掲する。下表ページに上表のK見出しを反復しない。
4. タイトルと見出しだけを前ページ末尾に残さず、少なくとも最初のデータ行と一緒に置く。表全体が1ページに収まるなら、残り高さ不足時は表全体を次ページへ送る。
5. 表間で改ページする場合、次ページ先頭の空白2行は省く。空白ページを作らない。
6. 結合見出しの途中を切らない。再掲行を対象件数・照合件数に数えない。

改ページで物理行番号が変わる場合は、先に行配置を決めて本来の各節点のK/Fセル位置を確定し、
その位置から数式・リンク・検証先を作る。これにより、汎用 `paginate()` に3列表を任せる必要をなくす。
共通処理が「入力根拠」の行を挿入した際の原値参照の更新は、先端主表にも引き続き適用する。
