# SNAPの杭部材とSDCの水平地盤ばね値の対応

`JibanShogenInfo98` の水平地盤ばね値に `58812` を入力する根拠は、**部材98が右基礎の1列目に属し、その部材区間1.300 mが、右SDCの第1層（層厚1.500 m）に収まるため**である。参照する値は、同層の「短期(非線形)-1列目」。

以下は、2026-09-17のユーザー説明と実ファイルを照合して記録したもの。ファイルの行番号は1始まりで、内容変更により移動するため、キー名と表の見出しも併せて確認する。

## 対象ファイル

パスはリポジトリのルートを基準とする。

| 役割 | ファイル |
| --- | --- |
| 杭部材・節点・地盤諸元の設定先 | `snap\今町橋りょう4P(C方向･右押し→).ndu` |
| 左基礎の地盤ばね値 | `snap\今町橋りょう4P(左).sdc` |
| 右基礎の地盤ばね値 | `snap\今町橋りょう4P(右).sdc` |

確認時点で、これらのファイルの文字コードはCP932（WindowsのShift_JIS系）。

## 1. KGInfoで杭部材の所属と参照SDCを決める

NDUの379行目以降に、杭グループと部材番号の範囲が記載されている。

```text
KGInfo1=13,18,41,4.893
KGInfo2=14,43,66,4.893
KGInfo3=15,68,91,4.893
KGInfo4=21,98,121,4.959
KGInfo5=22,123,146,4.959
KGInfo6=23,148,171,4.959
```

今回使用するのは、`=` より右側の**2番目・3番目のフィールドにある開始部材番号・終了部材番号**。両端を含む範囲として読む。

| 杭グループ | NDUの行 | 杭部材番号 | 参照するSDC |
| --- | ---: | --- | --- |
| `KGInfo1` | 379 | 18～41 | `今町橋りょう4P(左).sdc` |
| `KGInfo2` | 380 | 43～66 | `今町橋りょう4P(左).sdc` |
| `KGInfo3` | 381 | 68～91 | `今町橋りょう4P(左).sdc` |
| `KGInfo4` | 382 | 98～121 | `今町橋りょう4P(右).sdc` |
| `KGInfo5` | 383 | 123～146 | `今町橋りょう4P(右).sdc` |
| `KGInfo6` | 384 | 148～171 | `今町橋りょう4P(右).sdc` |

部材98は `KGInfo4` の範囲内なので、右SDCを参照する。このSDCの左右の対応は、今回のモデルについてユーザーから指定されたもの。

## 2. 基礎内の杭列位置から、表の列を決める

SDCファイル名の「右」は**右基礎**を表し、表の「1列目」などは**その基礎の中での杭列位置**を表す。

部材98は、右基礎の中では左側の杭列、すなわち**1列目**に属する。したがって、右SDCの「短期(非線形)-1列目」を使う。

2026-09-17の追加指定により、右SDCは `KGInfo4・5・6` に適用する。各グループのx座標は29.8、33.5、37.2で、左から順に右SDCの1列目、2列目、3列目に対応する。

参照する表は、右SDCの160行目から始まる「（２）直角方向」内の「b）水平地盤ばね値」（171行目）。173行目の列見出しは次の順序になっている。

```text
層番, 層厚(m),
長期-1列目, 長期-2列目, 長期-3列目,
短期(線形)-1列目, 短期(線形)-2列目, 短期(線形)-3列目,
短期(非線形)-1列目, 短期(非線形)-2列目, 短期(非線形)-3列目
```

「短期(非線形)-1列目」は、層番・層厚を含めて**CSVの9番目のフィールド（0始まりのインデックス8）**。水平方向ばね値の単位は、172行目の見出しにある `kN/m2`（kN/m²）。

左SDCの直角方向の水平地盤ばね表は159～168行目にあり、161行目の見出しでは杭列を「奇数列・偶数列」で区別している。参照先ごとに見出しを読み、右SDCの列位置や行番号をそのまま左SDCに流用しない。

## 3. ElementInfoとJointXYから部材区間を求める

NDUの483行目に、部材98の情報がある。

```text
ElementInfo98=3,0,0,0,98,99,75,0, , , ,0,0,98
```

`=` より右側の**5番目・6番目のフィールドが両端の節点番号**で、この部材では節点98と節点99を参照する。部材番号と節点番号は別の番号体系なので、両端節点は `ElementInfo` から取得する。

NDUの125～126行目から、その座標を読む。

```text
JointXY98=29.8,13.041,98
JointXY99=29.8,14.341,99
```

| 節点 | x座標（m） | y座標（m） |
| --- | ---: | ---: |
| 98 | 29.8 | 13.041 |
| 99 | 29.8 | 14.341 |

部材98はx座標が等しい鉛直部材なので、長さはy座標の差から求められる。

```text
部材98の長さ = |14.341 − 13.041|
             = 1.300 m
             = 1300 mm
```

このモデルの座標差はmとして読み、SDCの層厚もmにそろえて比較する。

## 4. 層厚を累積し、部材が位置する地盤層の行を決める

右SDCの174～180行目には、上から順に7層の水平地盤ばね値が並んでいる。層厚を累積すると、各層の範囲が分かる。

以下の深さは第1層上端を0とした相対深さ。本例では、部材98の上端（節点98）をこの基準として部材区間を対応させる。

| 右SDCの行 | 層番 | 層厚（m） | 累積深さの範囲（m） | 短期(非線形)-1列目（kN/m²） |
| --- | ---: | ---: | --- | ---: |
| 174 | 1 | 1.500 | 0.000～1.500 | 58812 |
| 175 | 2 | 1.300 | 1.500～2.800 | 310863 |
| 176 | 3 | 2.900 | 2.800～5.700 | 110708 |
| 177 | 4 | 2.600 | 5.700～8.300 | 268854 |
| 178 | 5 | 0.600 | 8.300～8.900 | 428981 |
| 179 | 6 | 9.500 | 8.900～18.400 | 403280 |
| 180 | 7 | 12.600 | 18.400～31.000 | 193733 |

部材98は杭の先頭部材で、相対深さ **0.000～1.300 m** に位置する。この区間全体が第1層の **0.000～1.500 m** に収まるため、**174行目**を選ぶ。

```text
相対深さ（m）
0.000  ├─ 第1層の上端／部材98の上端（節点98）
       │  部材98：長さ1.300 m
1.300  ├─ 部材98の下端（節点99）
       │  第1層の残り0.200 m
1.500  └─ 第1層の下端
```

層厚1.300 mの第2層があっても、部材長と層厚が等しいことを理由にその行を選ばない。選択の基準は、**層厚を累積した深さと、部材の上下端が位置する区間との対応**である。

## 5. 選んだ行と列の値をJibanShogenInfoへ入力する

右SDCの174行目は次のとおり。

```text
1, 1.500, 14703, 9802, 14703, 29406, 19604, 29406, 58812, 39208, 58812
```

第1層の「短期(非線形)-1列目」の値は **58812**。この値を部材98に対応する `JibanShogenInfo98` の水平地盤ばね値欄へ入力する。

実ファイルのNDUの656行目も、次のようになっている。

```text
JibanShogenInfo98= ,58812,1163,1307.5, , ,
```

入力位置は、`=` より右側の**2番目のフィールド（0始まりのインデックス1）**。先頭フィールドは空欄なので、カンマ区切りを読む際は空欄も保持する。部材長1.300 mは層の判定に使い、この転記では `58812` に部材長を掛けず、そのまま入力する。

対応関係は次の順序になる。

```text
部材98
  → KGInfo4（部材98～121）
  → 今町橋りょう4P(右).sdc
  → 直角方向／水平地盤ばね値／短期(非線形)-1列目
  → ElementInfo98 → 節点98・99 → 長さ1.300 m
  → 第1層（層厚1.500 m）内 → 174行目
  → 58812 → JibanShogenInfo98の2番目のフィールド
```

## 層境界をまたぐ部材の計算

2026-09-17の追加指定により、複数の層にまたがる部材は**重なり長さで加重平均し、最後に整数へ四捨五入する**。

```text
入力値 = 四捨五入［Σ(各層のばね値 × その層と部材の重なり長さ) / 部材長］
```

たとえば部材99は相対深さ1.300～2.600 mに位置し、第1層と0.200 m、第2層と1.100 m重なる。

```text
(58812 × 0.200 + 310863 × 1.100) / 1.300
= 272085.923076... → 272086
```

したがって、指定SDCの表示値から計算する `JibanShogenInfo99` の水平地盤ばね値は `272086` となる。3層以上にまたがる場合も、重なるすべての層の寄与を合計する。途中の積や和は丸めず、平均値を最後に `ROUND_HALF_UP` で整数に丸める。

## 確定した範囲と対象外の項目

この資料で確定したのは、ユーザー指定の `KGInfo1`～`KGInfo6` と参照SDCの対応、部材98の `58812` の選定・入力方法、および層境界をまたぐ部材の加重平均・整数四捨五入の方法。

- `JibanShogenInfo98` の他の値（`1163`、`1307.5`）の決め方は、本資料の対象外。
