### 3.2 維持する計算と保存仕様

- 直角方向・押込み側d表の地震時第1勾配をK、e表の降伏点（ρgfy考慮）をFの原値に使う。
- 各節点の負担区間は隣接節点との中点間。杭頭・先端は端部までの半区間。
- 地層、有効上端 `1/β`、有効下端 `杭長−根入れ` との重なりを積分する。
- `K = Σ(k_i × ℓ_i)`、`F = Σ(f_i × ℓ_i)`。平均のための除算、1.2補正、杭本数の追加乗算はしない。
- 合計後の `ROUND_HALF_UP`。既定K整数、F小数1桁。いずれも0～6桁指定を維持する。
- Kは `SuppotInfo` 第4・7・10・11・12・13欄、Fは第5・6・8・9欄へ反映する。
- 支点項目番号、節点番号、部材番号は別物。IDの連番や一致を仮定しない。
- 0抵抗の既存Y支点、丸め後0、先端の周面抵抗と先端ばねの合成が必要な入力等の拒否条件を維持する。
- 対象外支点・既存ケース値・改行・保存順序を保持し、`SuppotInfo` と `Suppot_ChokuKisoCaseNo` の対応を保護する。
- Excel編集をNDUへ戻す機能は追加しない。変換時の実入力は固定値として残す。

詳細は [周面入力仕様](fill-suppot-info-script.md)、[支点編集ルール](suppot-info-editing-rules.md) を参照。

### 5.2 帳票用記録の補足

現在の有効区間 `pieces` だけでは、主表に必要な第1・2層や除外区間を復元できない。
`complete()` が受け取る**実計算時のprofileと入力スナップショット**から、次を補足する。

1. `details.shaft.layers`（追加案）に全地層の番号・全層上下端・有効上下端・d/e表の出典行・CSV欄・列別K/F原値を保持する。
2. d表層厚とe表全層厚を別項目で残す。必要な元フィールドは渡された `sdc_raw` から取得する。ファイルの再読込みや異なる表の再選択をしない。
3. 全地層×選択SDC列のK/Fを `source_values` に収録する。基準入力では現状30原値から42原値になる。キーは引き続き `(shaft, SDC行, CSV欄)`。
4. 全節点は現行の `nodes[*].geometry` と `excluded[*]` の和集合から構成できる。KG・節点IDで重複を防ぎ、深さ順に並べる。必要なら内部の表示用構造へ正規化する。
5. 採用対象 `nodes`、`calculation.targets`、`fields` の意味・件数は変えない。除外・先端を表示したことを理由に採用対象へ追加しない。

JSONは既存項目を維持した追加変更とする案。現行リポジトリにスキーマ1の厳格な読込み分岐は見当たらないため、追加だけなら `SCHEMA_VERSION=1` を維持する。
外部利用が実装時に判明した場合は、追加項目の互換性を再確認する。

### 5.3 全節点の行生成

2シートで共通の幾何・行配置を一度決め、K/Fの原値と結果だけを変えて描画する。

1. KGブロックは `(SDC列番号, KG番号)` 順。各ブロックの節点は深さ順。任意のKG数・節点番号に対応する。
2. 地質層を `1/β` と `杭長−根入れ` で分割し、「有効／除外」を持つ連続した表示区間を作る。境界一致時に長さ0の行を作らない。
3. 各節点の負担区間と表示区間を交差させ、正の長さを持つ交差1件を1行にする。除外区間や原値0の層も表示する。
4. 各地質層の最初の行にA列、各表示区間の最初の行にB/C列を置く。除外で同じ層を分けてもA列の番号は繰り返さない。
5. 節点開始行にD全幅・F節点番号・G積分結果を置く。交差が1件ならEは空欄、複数なら各E行に内訳幅を置く。
6. データは縦結合しない。層境界／除外境界／節点境界に対応する罫線だけを引く。
7. ブロックごとに行数が異なるときは最長ブロックに全体を合わせ、短いブロック末尾を空欄とする。Σ行は全ブロック共通行に置く。
8. ΣはBの表示区間厚とDの節点全幅を一度ずつ足す。Eの内訳やページ継続表示を重複加算しない。末尾に見本同様の空白1行を確保する。

基準入力での期待配置は両シートともA1:U37、3ブロック×25節点・各33明細行、36行目Σ。
第4.4節の不整合を除き、代表セル位置と罫線構成を見本に合わせる。

### 5.4 数式と精度

節点深さを `z_j`、杭長をLとしたとき、負担上端・下端は次のとおり。

```text
内部節点: a_j=(z_(j-1)+z_j)/2、b_j=(z_j+z_(j+1))/2
杭頭:     a_j=0、b_j=(z_j+z_(j+1))/2
先端:     a_j=(z_(j-1)+z_j)/2、b_j=L
全幅:     w_j=b_j-a_j
区間幅:   ℓ_ji=max(0,min(b_j,区間下端_i)-max(a_j,区間上端_i))
K主表:    Σ(有効区間のK原値_i × ℓ_ji)
F主表:    Σ(有効区間のF原値_i × ℓ_ji)
```

除外区間のCセルには数値0を置く。有効区間のCは入力根拠の該当原値を参照する。
結果式は、単一区間なら `D×C`、複数なら `SUM(C区間アンカー×E内訳, …)`。
見本の空欄セルを0として使う式は再現しない。

K/F主表G列には最終 `ROUND` を入れず、丸め前の積分値を保持する。
入力根拠の採用再計算で `ROUND(主表結果, 設定桁数)` を行い、固定実入力と照合する。
これにより、主表と採用値の役割を分けながら原値編集への再計算を維持する。

長さ演算は既存 `length()` と同様、入力座標・層境界・条件の最大十進精度＋中点の1桁を保持する。
積の項や合計を途中で丸めない。採用値合わせの微小補正を加えない。
原値とPython Decimalの正確な計算文字列を残し、Excelの二進数値との差は採用段階で検証する。

表示は次の案とする。

- 長さ: 主表では小数3桁。計算値・入力根拠の正確な桁は保持する。
- K原値C: 基準入力は整数表示。将来の小数原値を隠さないよう、入力に小数がある場合は必要桁を表示する。
- F原値C: 基準入力は小数1桁。より細かい原値は必要桁を表示する。
- 結果G: K/F各設定桁数で表示。既定は見本どおりK整数・F小数1桁。採用値の末尾0の有無で表示桁を決めない。
- 数値0は数値として表示し、継続セルや単一区間のEの空欄とは区別する。

生成後のExcelで編集する原値はK/F数値を想定する。
KG・層数・節点・境界・除外条件を変えて行構成が変わる場合は、従来の案内どおりアプリから再実行する。
0支点が新たに必要になる変更でも、Excelから支点追加・NDU更新は行わない。

### 5.5 入力根拠・固定実入力・リンク

主表には一般説明や照合表を挿入せず、入力根拠の水平・土圧補足に続けて次を配置する。

| 補足 | 内容 |
| --- | --- |
| 周面条件・全地層 | 杭長、1/β、根入れ、全層厚とd表厚、有効区間、d/e原値出典 |
| 全節点の負担区間 | KG・SDC列・節点、前後節点、深さ、中点区間、全幅、有効幅、除外幅、周面対象／除外／先端 |
| 区間計算 | 節点×地層×有効／除外、上下端、長さ、K/F原値参照。主表の式がこの幾何・原値を読む |
| 採用照合 | KG・列・節点・支点項目・K主表値・K採用再計算・K固定実入力・K差・F主表値・F採用再計算・F固定実入力・F差（12列） |
| 実入力欄の対応 | K6欄、F4欄と各固定実入力値。既存情報を失わない |

採用照合は有効対象だけ（基準60行・120照合値）。固定実入力は `calculation.fields.after` を読み、黄色の定数セルとする。
採用再計算と固定実入力との差を数式にし、差≠0を強調する。`book.expected` も採用再計算セルを指す。
全節点の表示幅合計、各節点の内訳合計、有効長合計の幾何照合も設け、見本の0.460のような誤りを結果0だけで見逃さない。
これら照合結果から主表へ逆参照する循環を作らない。

原値は入力根拠に一元化する。同値の別SDC列をひとつのセルへまとめない。
同一SDC行・CSV欄を複数KGが意図的に共有する場合は、同じ原値参照でよい。

リンクは節点IDに加えてK/Fの表示先を区別する。
