# 水平地盤ばね値の入力スクリプト

実装: `scripts/fill_jiban_shogen.py`（Python 3.10以上、外部ライブラリ不要）。

参照する仕組みは [SNAPの杭部材とSDCの水平地盤ばね値の対応](snap-jiban-shogen-mapping.md)。

## 対象

既定の入力ファイルは、リポジトリ直下から見て次の2つ。

- SDC: `tests\data\今町橋りょう4P\今町橋りょう4P(右).sdc`
- NDU: `tests\data\今町橋りょう4P\今町橋りょう4P(C方向･右押し→).ndu`

2026-09-17のユーザー指定に基づき、既定では `KGInfo4`（98～121）にSDCの1列目、`KGInfo5`（123～146）に2列目、`KGInfo6`（148～171）に3列目を対応させる。合計72部材。部材範囲は実行時に `KGInfo` から読む。

SDCの選択方向にある水平地盤ばね表を使用し、NDUの `JibanShogenInfo` の第2フィールドに入力する。従来の「b）水平地盤ばね値 → 短期(非線形)-N列目」に加え、「b）設計水平地盤ばね値 → 液状化時-N列目」に対応する。既知見出しの完全一致で `seismic` / `liquefaction` を自動判定し、曖昧な部分一致は行わない。他のフィールド・対象外の部材・文字コード・改行は元のバイトを保持する。`--sdc-direction longitudinal` で橋軸方向、`transverse` で直角方向を選ぶ。既定は `transverse`。

2026-09-18、`短期(非線形)-奇数列/偶数列` にも対応。杭配置条件の実杭列数まで展開し、元CSV欄は `Layer.sources` に保持する。今町橋4Pの左SDCを左基礎へ入力する場合は `--sdc` と `--groups 1:1 2:2 3:3` を明示する。計算・丸め方式は共通。

同日、正確な `Ver.5.2.1` と5欄の旧見出しが一致する共有値形式にも対応した。
CSV第5欄の `短期(非線形解析)` を、杭配置条件の実杭列2列または3列へ共有する。
出典は各列へ複製せず、原行・第5欄を保持する。旧見出しでも別バージョン、杭列数1・4以上、
欄数不一致は拒否する。詳細は [対応計画と検証範囲](legacy-v521-sdc-support-plan.md)。

## 実行

PowerShellでリポジトリ直下から実行する。パスの既定値はスクリプトの場所を基準に解決するため、別の作業フォルダーからでも使用できる。

```powershell
# KGInfo4・5・6の全72部材の入力予定を表示
.venv\Scripts\python.exe scripts\fill_jiban_shogen.py
```

各部材について、相対深さ・現在値・入力予定値・参照SDCの行・各層との重なり長さを表示する。`--write` を省略するとファイルは変更しない。

同じコマンドに `--write` を付けるとNDUを更新する。`tests/data` はテスト原本なので、既定NDUへ
直接 `--write` せず、一時ディレクトリまたは `outputs` へコピーしたNDUを `--ndu` で指定する。
層境界は既定で重なり長さによる加重平均・整数四捨五入を適用する。

```powershell
Copy-Item "tests\data\今町橋りょう4P\今町橋りょう4P(C方向･右押し→).ndu" "outputs\水平ばね確認.ndu"
.venv\Scripts\python.exe scripts\fill_jiban_shogen.py --ndu "outputs\水平ばね確認.ndu" --write
```

更新前に、指定したNDUと同じ場所へ `.bak` を作成する。既存バックアップは上書きしない。
再実行時に既に同じ値なら、NDU・バックアップとも変更しない。

## 層境界の扱い

各グループの上端節点を相対深さ0とし、層厚を累積した区間と部材区間を照合する。この実装は、x座標が一定で、y座標が深い側へ増加する鉛直杭を対象にする。

部材区間が1層内に収まるときは、その層の値をそのまま入力する。部材長は掛けない。

2026-09-17のユーザー指定により、境界をまたぐ場合は**重なり長さで加重平均し、最後に整数へ四捨五入する**。既定値は `length-weighted`。各層の寄与を途中で丸めず、合計を部材長で割った後に `ROUND_HALF_UP` で丸める。以下の他の処理は、明示的に切り替える場合のオプション。

| `--cross-layer` | 処理 |
| --- | --- |
| `error` | 最初の境界横断部材でエラー。全体の書き込みを行わない。 |
| `length-weighted`（既定） | `Σ(各層のばね値 × 重なり長さ) / 部材長` を計算し、整数に四捨五入（ROUND_HALF_UP）。 |
| `midpoint` | 部材中央が入る層の値を使用。中央が境界と一致すると下側の層。 |
| `skip` | 境界横断部材は既存値を保持し、表示で「保留」とする。他の部材は処理する。 |

例: 部材99は第1層に0.200 m、第2層に1.100 m入る。右SDCの表示値を用いた計算は次のとおり。

```text
(58812 × 0.200 + 310863 × 1.100) / 1.300
= 272085.923076... → 272086
```

この数値は指定したSDCの表示値から計算する。既存の別NDUの数値を複写する処理ではない。

## 対象グループ・ファイルを明示する場合

`--groups` は `KG番号:SDC杭列番号` を指定する。指定すると既定の対応を置き換える。次のコマンドは、既定の3グループと加重平均の設定を明示したものである。

2026-09-18のユーザー指定により、杭のx座標とSDC列番号の昇順制約を廃止した。
`4:3 5:2 6:1` の逆順や、`2:3 3:3 4:3 5:2 6:1` のような同一SDC列の共用を許可する。
同じKGの重複指定、部材の重複、非鉛直・不連続などのデータ不整合は従来どおり拒否する。

```powershell
.venv\Scripts\python.exe scripts\fill_jiban_shogen.py --groups 4:1 5:2 6:3 --cross-layer length-weighted
```

`--sdc "パス"` と `--ndu "パス"` でファイルも変更できる。橋軸方向を使う例:

```powershell
.venv\Scripts\python.exe scripts\fill_jiban_shogen.py --sdc-direction longitudinal --groups 4:1 5:2 6:3
```

## 検証

```powershell
.venv\Scripts\python.exe -B -m unittest discover -s tests -v
```

見出しに基づく列選択、部材番号と異なる節点番号、累積深さ、層境界、四捨五入、対象フィールド以外のバイト保持、バックアップ、同じ値での再実行、書き込み前の異常検知を検証する。
