# SDC参照方向・応答変位法区分の選択対応 修正プラン

作成日: 2026-09-18  
状態: **ユーザー承認済み。2026-09-18に実装・自動検証・v1.4.0配布ビルド完了。**

互換性追記（2026-09-18）: 後続の液状化時SDC対応では、この画面の方向・土圧区分選択を変更せず、選択範囲内の既知見出しから地震時／液状化時を自動判定する。詳細は [液状化時SDC対応計画](liquefaction-sdc-support-plan.md)。

## 1. 目的

SDCからNDUへ値を取り込む際、現在固定されている次の条件を利用者が選択できるようにする。

- SDC参照方向
  - `（１）橋軸方向`
  - `（２）直角方向`
- 有効抵抗土圧力の区分
  - `応答変位法以外の場合`
  - `応答変位法の場合`

方向は4工程すべてに適用する。応答変位法区分が存在するのはSDCの `c）有効抵抗土圧力` だけなので、後者は有効抵抗土圧力工程だけに適用する。水平地盤ばね、杭周面、杭先端の計算条件まで応答変位法区分で切り替えることはしない。

既定値は現行互換の `（２）直角方向`・`応答変位法以外の場合` とし、既存API・CLIを追加指定なしで呼んだ場合の変換結果を変えない。

## 3. 現在の固定箇所

### 3.1 GUIと共通API

- `scripts/sdc_converter_app.py`
  - 方向・応答変位法区分の入力部品がない。
  - 画面説明も「直角方向・短期」と固定表示している。
  - `App.request()` は方向・区分を渡さない。
- `scripts/portable_converter.py`
  - `Request` にSDC参照方向・土圧区分がない。
  - `prepare()` は4パーサを選択条件なしで呼ぶ。
  - JSONの `configuration` に選択条件が残らない。

現在の `push_direction` は、土圧列を右押し／左押し／直接指定のどれとして解釈するかを表す。今回追加する「橋軸方向／直角方向」とは別概念であり、名前・画面・報告書を混同しない。

### 3.2 SDCパーサ

| 工程 | 現在の入口 | 固定内容 |
| --- | --- | --- |
| 水平地盤ばね | `fill_jiban_shogen.parse_sdc()` | `（２）直角方向` の `b）水平地盤ばね値` |
| 有効抵抗土圧力 | `fill_jiban_pressure.parse_pressure_sdc()` | `（２）直角方向` の `c）有効抵抗土圧力` → `応答変位法以外の場合` |
| 杭周面 | `fill_suppot_info.parse_sdc()` | `（２）直角方向` の d/e表 |
| 杭先端 | `fill_pile_tip_suppot_info.parse_sdc()` | `（２）直角方向` の f/g表 |

各パーサの方向範囲終端は、現在「直角方向の次に来る `（３）` 以降、またはEOF」を前提にしている。橋軸方向を選ぶ場合は `（２）直角方向` を終端として切り出さないと、同名のb～g表が2個見つかり、誤読または重複エラーになる。このため、見出し文字列を置換するだけの修正では不十分である。

### 3.3 KG候補・SDC列の選択

- `kg_candidates.inspect_candidates()` は `fill_jiban_shogen.parse_sdc()` を使って地層厚と選択可能列を取得するため、現在は直角方向固定である。
- `KGSelection` はSDC/NDUパス変更時だけ再読込し、方向変更を監視しない。
- 列の仮設定と右押し／左押し一括設定は最大3列へ固定されている。

実右SDCでは橋軸方向が5列、直角方向が3列である。橋軸方向選択後も3列で打ち止めにすると4・5列目を正しく自動設定できない。上限は固定値3ではなく、選択方向から得た実杭列数にする必要がある。

### 3.4 計算記録・Excel

- `calculation_record.py` は実際に採用した行・CSV欄を記録できる構造になっている。選択方向のパーサが正しい `source_line` / `SourceColumn` を返せば、橋軸方向や応答変位法の場合の原値も同じ仕組みで記録できる。
- 一方、JSON設定とExcel主表には選択した方向・土圧区分が明示されない。値だけを見て参照表を判別させないため、両方へ表示・記録が必要である。
- `excel_cli.py` の土圧照合用再計算は `parse_pressure_sdc()` を別途呼んでいるため、共通 `Request` だけ直しても照合処理が旧固定条件へ戻る。この経路も同じ選択値を渡す必要がある。

| 方向 | 実杭列数 | 水平 | 土圧・以外 | 土圧・応答 | 周面d/e | 先端f/g |
| --- | ---: | --- | --- | --- | --- | --- |
| 橋軸 | 3 | 見出し29、データ32～38行 | 見出し41、データ45～51行 | 見出し53、データ57～63行 | 65／97行 | 129／147行 |

左SDCは奇数列／偶数列、土圧は1・2列目と3列目以降の奇偶を共有する形式である。今回の方向選択でも、現在の `sdc_columns.resolve()` による「実杭列 → 元CSV欄」の対応を維持する。橋軸方向用に番号列形式へ決め打ちし直してはいけない。

なお左SDCの橋軸方向では、調査データ上、土圧の「以外」と「応答」が同値である。区分切替の回帰テストは値が異なる右SDC、または値を明示的に変えた最小fixtureで行う。

## 5. 目標仕様

### 5.1 GUI

入力ファイル欄と項目・杭対応欄の間、または項目・杭対応欄の先頭に、編集不可の選択欄を2つ追加する。

| 画面項目 | 選択肢 | 初期値 |
| --- | --- | --- |
| SDC参照方向 | `（１）橋軸方向` / `（２）直角方向` | `（２）直角方向` |
| 有効抵抗土圧力 | `応答変位法以外の場合` / `応答変位法の場合` | `応答変位法以外の場合` |

- SDC参照方向を変更したら、SDC列の意味・列数・層厚が変わり得るため、KG選択と列指定を直ちに解除して再読込する。
- 応答変位法区分の変更ではKG選択を維持し、Excelプレビュー／保存済み状態だけを無効化する。
- 有効抵抗土圧力工程が未選択の間は区分欄を無効表示にしてよい。ただし保持値は変えず、再選択時に復帰させる。
- 処理中は既存入力と同様にロックする。コンボボックスは通常時も手入力不可の `readonly` とする。
- 現在の固定説明文は、選択内容を重複記載する文章ではなく、選択方向を4工程に使うこと、応答変位法区分は土圧だけに使うことが分かる文へ変える。

### 5.2 共通API

`portable_converter.Request` の末尾に、既存の位置引数互換を壊さない既定付き項目を追加する。

```text
sdc_direction = "transverse"       # longitudinal / transverse
pressure_case = "non-response"     # non-response / response
```

内部値と日本語表示は一か所の定数で対応付ける。`push_direction` は現状のまま独立して保持する。

全経路は次の選択を使う。

```text
GUI / CLI
  -> Request.sdc_direction
       -> KG候補の層厚・列一覧
       -> 水平、土圧、周面、先端の各SDCパーサ
  -> Request.pressure_case
       -> 土圧パーサだけ
  -> 計算結果
       -> NDU、JSON、Excel、プレビュー
```

### 5.3 CLI

4つの単独CLIとExcel共通経路に、同じ語彙のオプションを追加する。

- 全工程: `--sdc-direction {longitudinal,transverse}`
- 土圧工程: `--pressure-case {non-response,response}`

既定値はGUI・APIと同じにする。土圧以外のCLIへ `--pressure-case` は追加しない。ヘルプには日本語見出しとの対応を併記する。

### 5.4 KG列の設定

- コンボボックスの候補は選択方向の全実杭列を表示する。右SDC橋軸方向なら1～5列を表示する。
- チェック直後の仮設定も全候補列を対象とし、未使用の小さい列を優先する。全列使用済みなら最大列を共有する。
- 右押し／左押しの一括設定は `max(catalog.columns)` を上限とする。
  - 5列・5杭: 左押し `1,2,3,4,5`、右押し `5,4,3,2,1`
  - 5列・6杭: 左押し `1,2,3,4,5,5`、右押し `5,5,4,3,2,1`
  - 現行3列では従来どおり `1,2,3,3…`／`…3,3,2,1`
- 同一列の共有、手動変更、x座標順、`push_direction="direct"` という現行v1.3.0の仕様は維持する。

### 5.5 記録と表示

- JSON `configuration` に内部値と日本語表示を記録する。
  - `sdc_direction`
  - `sdc_direction_label`
  - `pressure_case`
  - `pressure_case_label`（土圧未選択なら `null` または `not-used` を明示）
- `calculation.source_values` は選択表の実行・実欄を記録し、原CSV値との照合を維持する。
- Excel各主表のタイトルまたは直下の見出しに参照方向を表示する。
- 有効抵抗土圧力シートには方向と応答変位法区分の両方を表示する。
- Excelプレビューも同じセルモデルを使うため、保存Excelと同じ表示になることを確認する。
- 既定条件でもNDUの出力バイトは現行と一致させる。表示追加によりExcelのバイト一致までは要求しないが、計算値・式・採用原値・印刷範囲を維持する。

## 6. 実装設計

### 6.1 共通のSDC範囲選択

`scripts/sdc_columns.py` に次を集約する。

- 内部値と日本語見出しの定数
- 値の妥当性検査
- 選択した方向見出しがちょうど1個あることの検査
- 選択方向の開始行と、次のトップレベル方向見出し直前までの終端を返す処理
- 土圧区分見出しの対応

トップレベル見出しは完全一致する方向見出しを優先し、単なる行番号や「次は3以上」という前提を使わない。選択方向内に必要な表がない場合は、内部英語値ではなく日本語の方向・表名を含むエラーにする。

### 6.2 4パーサ

- `fill_jiban_shogen.parse_sdc(raw, sdc_direction=...)`
- `fill_jiban_pressure.parse_pressure_sdc(raw, sdc_direction=..., pressure_case=...)`
- `fill_suppot_info.parse_sdc(raw, sdc_direction=...)`
- `fill_pile_tip_suppot_info.parse_sdc(raw, sdc_direction=...)`

各パーサは共通ヘルパーで得た方向範囲内だけを探索する。列形式、単位、層番、層厚、正値、杭長、除外範囲、水平・回転先端ばね0など、現在の厳格な検証は緩めない。

戻り値へ方向・土圧区分の情報を重複保持する必要はない。共通 `Request` とJSON設定を正とし、出典行・欄は既存のProfile／Layerに保持する。ただし単独CLI報告書にも同じ設定を必ず書く。

### 6.3 共通変換と候補読込

- `portable_converter.prepare()` で2設定を検証し、該当パーサへ渡す。
- `require_matching_lengths=True` の再検査でも同じ `sdc_direction` を `inspect_candidates()` へ渡す。
- `kg_candidates.inspect_candidates()` は選択方向の水平地盤ばね表から厚さ・列一覧を作る。
- `KGSelection` は方向変数を受け取り、方向変更をSDCパス変更と同じ世代管理付き非同期再読込へ流す。
- 応答変位法区分は候補読込へ渡さない。

### 6.4 GUI状態管理

- `App` に方向・土圧区分用 `StringVar` を追加する。
- `invalidate()` の監視対象へ両方を追加する。
- 方向変数は `KGSelection` 自身でも監視し、変更時に選択解除する。
- 土圧チェックボックスの変更時に区分コンボの活性状態を更新する。
- `apply_states()` で処理終了後に `readonly` を復元し、通常のテキスト入力状態へしない。
- `App.request()` で内部値へ変換して `Request` に渡す。

### 6.5 CLI・照合経路

- 4単独スクリプトのargparseへ上記オプションを追加し、パーサ呼出し・標準出力・JSONへ反映する。
- `excel_cli.run()` は `Request` 作成時に設定を渡す。
- 土圧の `--reference` 再計算でも `request.sdc_direction` と `request.pressure_case` を使う。
- 既存の `right` / `left` / `direct`、境界処理、丸め桁、周面profileは変更しない。

### 6.6 帳票・配布

- `calculation_record.py` は現在作業ツリーにあるSourceColumn対応変更を保ったまま、選択表の出典を記録する。
- `excel_report.py` は設定ラベルを各主表へ渡し、値・数式の依存関係を変えず表示だけを追加する。
- `portable_smoke.py` はGUI既定値、方向変更時の列候補、応答変位法変更時の土圧値、保存結果を確認する。
- 現在の未コミットv1.3.0が左SDC対応として使われているため、本機能を配布する版は原則 `1.4.0` とする。
- `build_portable.py` で全テスト後にEXEを作成し、展開後EXEでも両方向と土圧両区分を通す。実案件データはZIPへ含めない。

## 8. 検証計画

### 8.1 パーサ単体

1. 右SDCの橋軸／直角で、4パーサの層数、杭列数、出典行、出典欄、代表値を独立期待値と照合する。
2. 土圧は2方向×2区分の4組合せを検証する。
3. 左SDCの両方向で、奇数・偶数列の共有元欄が正しいことを検証する。
4. 選択外方向に同名表や壊れた値があっても選択範囲を越えて混同しないことを確認する。
5. 選択方向の欠落・重複、区分欠落・重複、単位不一致、列数不一致は保存前に日本語エラーにする。

### 8.2 KG選択

1. 右SDC橋軸で列候補 `(1,2,3,4,5)`、直角で `(1,2,3)` になる。
2. 方向変更直後に選択・列指定・モデル赤色が解除され、古い非同期結果を採用しない。
3. 5列時の左押し／右押しと、列数を超える杭数の最大列共有を確認する。
4. 応答変位法区分だけの変更ではKG選択・モデル赤色を保持する。
5. `prepare()` 直前の実バイト再検査も選択方向を使う。

### 8.3 変換統合

1. 右SDC・橋軸方向で4工程を同時実行し、水平72部材、土圧72部材、周面60節点、先端3節点の対象と計算根拠を確認する。
2. 土圧の2区分で、2列目等の値が異なる部材だけ期待どおり変わることを確認する。
3. 方向変更では水平・周面・先端も選択方向の原値へ変わることを確認する。
4. 既定値の `Request` は現状の207件となり、指定NDUに対する出力SHA-256 `31e9e85971d07ae1a0b21273f500b0d8d039184ecf9febb6db642fbfabfbd22a` を維持する。
5. 選択外KG、他方向支点、対象外フィールド、入力SDC/NDUを変更しない。
6. 再実行が同一結果になり、別名保存・元ファイル更新・バックアップ・競合検知を維持する。

### 8.4 JSON・Excel
