# Excel計算過程出力とプレビュー

実装日: 2026-09-17。元仕様は [sdc-excel-calculation-report-spec.md](sdc-excel-calculation-report-spec.md)。

## 利用方法

GUIの「Excelをプレビュー」で、メモリ上の帳票を「計算過程Excel」タブに表示する。
シート選択、表示位置、倍率、縦横スクロール、識別列固定、セルの数式・完全な値の表示、
内部リンクから明細への移動ができる。入力・出力設定を変えると表示は無効になる。
NDUモデル図とKG編集は「入力・保存設定とモデル」タブに残す。

「変換して保存」はモデル、JSON、既定オンのExcelを同一実行IDで保存する。
チェックを外した場合も帳票プレビューは使用でき、xlsxの保存だけを省略する。
保存済みExcelは独立したボタンで関連付けアプリから開ける。開く操作の失敗は保存結果を取り消さない。

開発環境では `uv pip install --python .venv/Scripts/python.exe -r requirements.txt` を実行し、
従来のVS Code F5構成、または `scripts/sdc_converter_app.py` から起動する。
配布EXEにはXlsxWriterを同梱し、利用PCでExcel・Node.js・Pythonの追加インストールは不要。

4つの個別CLIに `--excel-report path.xlsx` を追加した。
未指定時は従来のCLIを通す。モデル出力オプションを省略するとExcelだけの計算確認になり、
帳票に「計算確認・モデル未保存」と表示する。水平のmidpoint/skip、土圧のendpoints/左押し、
丸め桁数等を維持する。周面でモデルを書き出す場合のprofile明示も維持する。

## 構成

- `calculation_record.py`: 計算に使用したパーサの戻り値、入力スナップショット、最終NDUから
  出典、幾何、実入力846欄、変更前後、除外、支点・ケース構造を記録。表示文字列を再解析しない。
- `excel_report.py`: 6シートの共通セルモデルと限定数式AST。四則演算、MAX/MIN/SUM/ROUNDを
  同じASTからExcel式・計算済みキャッシュに変換する。最終値をDecimalの実入力と照合し、
  不一致時は対象とセル・式を示して失敗する。xlsx公開前にZIP/XMLを読戻して全式・数値・空欄を照合する。
- `excel_preview.py`: 上記セルモデルをTk Canvasに表示する読取専用プレビュー。
  出力Excelとシート・セル位置・数式・値・色を共用する。外部で編集された任意のxlsxを読み込む機能ではない。
- `portable_converter.py`: 既存のDecimal計算は維持し、共通記録・帳票・保存を統合する。
- `excel_cli.py`: Excel指定時の個別CLIの記録と保存。共通のstage/publish_new/verify_sourcesを使用。

SDC原値参照のキーは「処理＋SDC行＋CSV欄」。同値の1列目と3列目も別セルを参照する。
日本語シート参照は引用符付き。先端の負側制限値は実際の空セル。
数値の原十進文字列とDecimalの丸め前文字列も残す。実入力は固定値で、Excel編集からNDUへ戻さない。

座標の二進引算誤差が丸め境界を変えないよう、座標演算に限って入力座標・層境界・条件の
最大十進精度＋中点の1桁を保持するROUNDを用いる。元精度を切り捨てず、微小値の加算はしない。
補間土圧・台形積分・加重和は途中で丸めず、既存ルールの最終桁だけを丸める。

印刷はA4横、列幅から用紙の有効幅へ収まる倍率を算出し、縦は必要ページ数とする。
列幅の基準となるNormal書式はテーマに依存しないCalibri 11に固定し、日本語Excelでも横幅を維持する。表示セルは游ゴシックを使用する。
複数種類の表があるため、改ページごとにその表の見出しを再掲する。
ExcelのFitToPagesは手動改ページを無効にするため併用しない。
見出し挿入に伴うセル位置変更は、数式AST・内部リンク・検証セルへ一括反映する。

## 保存の境界

Excelを先に生成・検証し、モデル・JSON・Excelを保存先の一時ファイルへ書いて読戻し、
必要なバックアップを作成して帳票を公開し、入力を再検証して最後にモデルを公開する。
通常失敗では、この実行が公開し、内容とファイルIDが変わっていない帳票だけを取り消す。
作成したバックアップは保持してエラーにパスを付記する。Excel既存ファイルは再利用しない。
複数ファイルの公開は一括原子的ではなく、強制終了時には帳票だけが残る可能性がある。

## 検証

既存回帰に加え、全対象・区間数、最終846欄、Fractionによる独立積分、空欄6欄、
周面除外12節点、非連番先端・小数値、部分項目・部分杭列、非既定CLI設定、
原値変更で別杭列に影響しないこと、固定実入力の保持、Excelオン/オフ同一モデル、
生成失敗・Excel/JSON/モデル公開失敗・他プロセスによる帳票差替えの保持、GUI切替・無効化を検証する。

Microsoft Excel 16.0の独立インスタンスで、全348最終再計算セルと全4,486数式セルを再計算し、
値・キャッシュの一致を確認した。SDC原値変更に応じた再計算、変換時実入力の固定保持も確認した。
実機検証は生成した検証用ブックだけを対象とし、入力原本と参考Excelには保存しない。
全6シートの代表範囲をExcel出力PDFから画像化して表示・数値書式・空欄を確認する。
Input-JR/JRSNAPでの解析実行、別クリーンPC、署名は今回の検証に含めない。
