## 4. 削除方式はB案を採用

2026-09-18のユーザー指定により、初稿の推奨A案を取り下げ、B案に変更する。
ここで「主表」とは、残す5枚のシートにある計算表のこと。「原値」とは、SDCから読み取った計算前の数値のこと。

| 案 | 内容 | 今回の扱い |
| --- | --- | --- |
| A | 元の補足情報を主表の下部へ移す | 採用しない |
| **B** | **原値を計算表へ直接書き、必要な計算はその表のセルと数式で行う** | **ユーザーが選択** |
| C | 原値まで数式の中の数値に埋め込む | 採用しない。編集する原値はセルに置く |
| D | 計算結果もすべて固定値にする | 採用しない。平均・補間・積分は式として残す |
| E | 2枚を非表示にする | 採用しない。2枚のシート自体を削除する |

B案では、Excelに主表下部の補足表や、右側の隠し計算欄を追加しない。

## 6. B案の詳細

### 6.1 原値と計算式をどこへ置くか

基準入力の既存の主表配置を使い、各KGのブロックごとに次のように組み立てる。
下表の列は最初のブロックの位置。2番目以降にも同じ規則を適用し、特定のKG数・行数に固定しない。

| 主表 | 数値として直接置く欄 | 同じ主表内で行う計算 |
| --- | --- | --- |
| 水平地盤ばね | C列のKh原値、B列の層厚、D列の部材長、E列の重なり長 | G列の原値参照・長さ加重平均。Σも主表のセルを集計 |
| 有効抵抗土圧 | C列の層上下の原土圧、B列の層厚、D列の部材長、E列の区間長、F列の深さ | G列の線形補間、I列の台形積分による平均または上下端採用 |
| 杭周面ばね | C列のK原値、B列の区間厚、D/E列の分布全幅・内訳幅 | G列の原値×幅の積分 |
| 杭周面の支持力 | C列のF原値、B列の区間厚、D/E列の分布全幅・内訳幅 | G列の原値×幅の積分 |
| 杭先端ばね | 上表B/C列のK1/K2、下表B/C列のFy/Fu | 4量はもともと直接転記なので、追加計算はしない |

長さ・深さは現行の計算記録から取得した丸め前の数値を置く。表示だけを小数3桁にする。
現在空欄になっている単一層のE列などを、見た目の都合で0や重複値に変えない。

先端の12セルは、旧シートを参照する数式から**SDC原値そのものの数値セル**へ変わる。
これは計算済み平均値などを一律に固定するD案とは異なり、先端の「原値をそのまま転記する」という既存ルールに沿う。

### 6.2 繰り返し表示する原値の扱い

- 原値キー `(operation, SDC行, CSV欄)` を内部記録で維持する。同じ値でも別列・別量なら別の原値として扱う。
- 同じシート内で同じ原値を何度も表示する場合は、主表内の最初の適切な表示セルに数値を置き、以後はそのセルを参照する。編集元が複数に分かれないようにする。
- たとえば水平の同じ地層が複数行に現れる場合、最初のCセルを編集すると同じ原値を使う行の計算が連動する。別SDC列の同値セルには連動させない。
- 同じSDC列を複数KGが共有する場合も同一キーへの参照を使う。別KGだからという理由だけで原値を複製しない。
- 周面KとFはそれぞれ自分のシートの原値を使う。幾何値は同じ計算記録から両表へ置き、FがKシートの補足領域を読む構成にはしない。
- 周面の除外区間の原値表示は数値0を維持する。計算に使わない除外部分のSDC原値を並べるための別表は作らず、元の記録をJSONへ残す。
- 長表の続きページで再掲する原値・全幅・結果は、最初の表示セルへの参照を使う。再掲分をΣへ二重加算しない。

### 6.3 平均・補間・積分の組み直し

**水平:** 単一層は主表の原値参照、複数層は主表の `Σ(Kh×重なり長)÷部材長` を使う。
中央採用は現行のルールで選んだ主表の原値セルを参照し、保留は記録上の保持値または空欄をそのまま置く。

**土圧:** G列の補間は、主表に置いた層上側/下側原値、深さ、層厚を使う。
主表に独立した欄がない「元の地層の上端深さ」は、生成時の確定した幾何定数として式に含める。
層途中から始まる部材で、区間の開始深さを元の層上端として代用してはいけない。
I列の平均は各区間の `((上端補間値＋下端補間値)÷2)×区間長` を主表参照で合計し、部材長で割る。
単一層・上下端採用では従来どおり主表の補間結果を使う。別表へ台形積分の中間値を置かない。

**周面K/F:** 各表内の原値と幅から、1区間なら積、複数区間なら積の和を求める。
除外0、先端の周面抵抗0、既存の負担幅・有効区間を維持する。

主表の表示丸めと採用時のROUNDを区別する。補間・積分を途中で丸めたり、係数・本数・微小な補正値を追加したりしない。
必要な座標演算の保持桁は、現行の「入力座標等の最大十進精度＋中点用1桁」を維持する。

原値の編集による再計算は残すが、幾何・杭列・地層構成・除外境界・計算方法を変える場合はアプリで再生成する。
主表の長さ欄だけを編集して区間分割全体を自動で作り直す機能は追加しない。
土圧式へ含める幾何定数と、セルに置く抵抗値・土圧原値を混同しない。

### 6.4 検証と固定実入力の扱い

B案では主表だけを残すため、旧「入力根拠」の固定実入力・採用ROUND・差の表をExcelに再作成しない。
**原値編集後に、Excel内の差欄が赤くなる機能はなくなる。生成時にアプリが正しさを検証する機能は維持する。**
これはB案の仕様として明示し、旧A案の「Excel内の501差を維持」と取り違えないようにする。

- 現行 `book.expected` は「検証セル」を指定する形式。B案では主表の値または主表セルから組み立てた採用式を評価し、独立した `calculation.fields.after` と比較できる形へ変更する。
- 水平の加重平均、土圧、周面K/Fの採用ROUNDは検証用のメモリ上の式とする。原値を直接採用する水平・先端は、その数値または主表参照を評価する。
- 基準348採用値の比較対象を維持する。補足セルが消えたことを理由に336件の検証を捨てない。
- 周面の全幅・有効幅150件、先端の杭長3件も生成時の検証として維持する。周面は主表の幅・生成区間と独立した幾何記録を照合し、先端はNDU座標差とSDC杭長を照合する。
- `Sheet.checks` の501個の表示セルと条件付き書式は廃止するが、対応する348採用・153幾何の検証内容は内部の検証項目に置き換える。比較する両辺を同じ値から作って常に成功させない。
- 不一致は工程・KG・対象・量・式または値を示して失敗する。原値が数値セルになっても、エラー表示が `.formula` の存在を前提にして二重失敗しないようにする。
- 原値変更の回帰試験では、更新すべき主表結果が変わり、固定実入力の記録が不変で、再検証時に対象の不一致を検出できることを確認する。

Excelで編集した内容をアプリやNDUへ自動で戻す機能はない。
正負10欄と負側の空欄、原値の正確な十進文字列、変更前後、出典・幾何・条件は既存の内部記録とJSONへ保持する。
主表に表示しない情報を削除したり、再計算値で変換時実入力を上書きしたりしない。

### 6.5 表の見た目・印刷・情報の保存先

主表下部の補足表、12列への拡張、補足用の印刷範囲制御は追加しない。

既存のA4縦、倍率、余白、見出し反復、手動改ページ、フッターを維持する。

Excelの数式がJSON・元のSDC/NDUや他ブックを読みに行く構成にはしない。

### 6.6 セルモデル・GUI・内部リンク

- `build()` は選択された主表だけを生成する。「変換結果」「入力根拠」は一時的な隠しワークシートとしても生成しない。

- 結合セル選択、倍率、スクロール、設定変更時の無効化、保存ワーカー、保存Excelを開くボタンを維持する。

### 6.7 保存・CLI
