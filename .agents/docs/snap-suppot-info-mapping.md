# SuppotInfoと杭周面の鉛直地盤ばね・支持力の対応調査

調査日・画面照合による更新日: 2026-09-17。対象は `snap/今町橋りょう4P(C方向･右押し→).ndu` と右基礎SDC。

**単位換算は、SDCの分布値に節点の負担区間との重なり長さを掛けて合計する。** 現行データでは隣接節点との中点で負担区間を区切ると、既存のばね値の分布を説明できる。ユーザー提示の入力画面により13フィールドの項目名・並びは確定した。ただし、現行SDCと既存NDUの完全一致にはならない。支持力の係数、各勾配の採用値、引抜き側端部には未確定事項があり、本資料は確定済みの自動入力仕様ではない。

今回作成したもの:

- [suppot-info-verification.json](suppot-info-verification.json): 75節点の区間、SDC行、押込み／引抜き双方の第1・第2勾配と降伏・終局の計算、既存60支点との差分。

後続の入力スクリプト `scripts/fill_suppot_info.py` を作成・レビュー済み。NDUとNDTに対応し、既存画面方式を明示的に選択して使用する。[使用方法・対応範囲・レビュー結果](fill-suppot-info-script.md)を参照。以下の調査は押込み／引抜き・各勾配を別々に検討したもので、入力スクリプトの限定profileと区別する。

杭先端支持は別途 [先端ばね・支持力の対応調査](snap-pile-tip-suppot-info-mapping.md) と [先端入力スクリプト](fill-pile-tip-suppot-info-script.md) に記録した。先端の既存配置の再現であり、以下に残る周面抵抗との合成の論点は対象外。

## 1. 支点番号と節点番号を区別する

## 3. 「区間の長さ」は節点の負担区間から求める

右杭の上端はy=13.041 m。相対深さ `z = y − 13.041` とする。

内部節点jの負担区間を、上下の隣接節点との中点間とする:

```text
aj = (z前 + zj) / 2
bj = (zj + z次) / 2
```

最上端は杭上端、最下端は杭先端で打ち切る。節点番号の加減算ではなく、杭部材の接続から隣接節点を取得する。

層iの有効区間を `[ui, vi]` とすると、実際に掛ける長さは次の値:

```text
ℓij = max(0, min(bj, vi) − max(aj, ui))
K1j = Σ(k1i × ℓij)  [kN/m² × m = kN/m]
K2j = Σ(k2i × ℓij)  [kN/m² × m = kN/m]
Fyj = Σ(fyi × ℓij)  [kN/m  × m = kN]
Fuj = Σ(fui × ℓij)  [kN/m  × m = kN]
```

押込み側・引抜き側はそれぞれの有効区間と表で計算する。ここでは部材長で割らない。前回の水平地盤ばねに対する「加重平均」と異なり、分布値を節点ばねへ集約するための積分である。

この中点分割は既存値から強く支持される解釈。ただし区間定義を明記した元の入力手順書は未取得であり、以下の全差分を残す。

### 例A: 節点106（SuppotInfo65）―第6層の内部

前後の節点は105・107。相対深さは9.1・10.4・11.7 mで、負担区間は **9.75～11.05 m、長さ1.3 m**。

```text
K1 = 168029 × 1.3 = 218437.7 kN/m
K2 =   3006 × 1.3 =   3907.8 kN/m
Fy = 2117.2 × 1.3 =   2752.36 kN
Fu = 2470.0 × 1.3 =   3211.0 kN
```

これは現行SDC表示値からの計算で、既存レコードの `218435,2293.6,...` の完全再現値ではない。

### 例B: 節点102（SuppotInfo61）―上端除外と層境界を含む

負担区間は **4.55～5.85 m**。深さ4.945 mまで除くため、第3層0.755 mと第4層0.150 mを負担する。

```text
K1 = 46127 × 0.755 + 112020 × 0.150 = 51628.885 kN/m
K2 =   396 × 0.755 +   2004 × 0.150 =   599.580 kN/m
Fy = 294.1 × 0.755 + 1411.5 × 0.150 =   433.7705 kN
Fu = 343.1 × 0.755 + 1646.7 × 0.150 =   506.0455 kN
```

層全体の⊿lをすべての節点へ掛けるのではなく、**その節点の区間との重なり**を使う。

### 例C: 節点121（SuppotInfo80）―杭先端付近

前後の節点120・121・122の深さは28.6・29.9・31.0 m。負担区間は **29.25～30.45 m**。

| 側 | 有効区間 | 有効長 | K1（kN/m） | Fy（kN） |
| --- | --- | ---: | ---: | ---: |
| 押込み | 29.25～29.70 | 0.45 m | 36324 | 232.875 |
| 引抜き | 29.25～30.45 | 1.20 m | 96864 | 621.000 |

既存NDUは画面の＋側・−側のばね定数／制限値が同値で、押込み側0.45 m相当の `36323,194.1` が入っている。引抜き側1.20 mの集約値は再現していない。画面の＋／−とSDCの押込み／引抜きの物理的対応は、項目名の確定とは別に確認する。

さらに節点122の **30.45～31.0 m（0.55 m）** は、SDCでは引抜き側の周面抵抗がある。K1=44396 kN/m、Fy=284.625 kN。ただし既存SuppotInfo124は杭先端支持のレコードなので、これをそのまま周面ばねで置換してはいけない。先端支持と同じ節点に集約する方法は未確定。

```text

```

```text

```

## 5. 既存値との差と未確定事項

比較用にKを整数、Fを小数1位へROUND_HALF_UPで丸めた。**これは今回の差分表示用であり、SuppotInfoへの最終入力の丸め仕様としてユーザー確認済みではない。** 計算中は丸めていない。

| 比較 | 右基礎60支点中の一致数 | 最大絶対差 |
| --- | ---: | ---: |
| 現行SDCのK1積分 vs 第4フィールド | 0 | 3 kN/m |
| 現行SDCのFy積分 vs 第5フィールド | 0 | 458.8 kN |
| 調査用のFy積分÷1.2 vs 第5フィールド | 40 | 0.1 kN |

1. **支持力の係数:** 現行SDCの降伏点を約1.2で割ると既存値に近い。係数を除外した旧入力や元SDCの版・計算条件の相違は候補だが、原因は特定していない。1.2除算を入力規則にしてはいけない。ばね値の差も、表示丸めだけが原因と断定していない。
2. **第2勾配・終局:** 既存周面支点は第4=7=10=11=12=13、第5=6=8=9という形。現行SDCの小さい第2勾配と大きい終局点をそのまま別々に転記した形ではない。この設定が意図的か確認が必要。
3. **引抜き側端部:** SDCは先端まで周面抵抗を考慮するが、既存支点は押込み側相当の値と同値。先端節点での周面抵抗の合成方法も未確定。
4. **第3勾配の採用値・丸め・正負の物理的対応:** フィールドの割付けは画面で確定した。SDCのd表には第3勾配の欄がないため、その設定規則は別に決める必要がある。最終入力の丸め、画面の＋／−とSDCの押込み／引抜きの対応も画面だけでは確定しない。

調査中の質問に対し、ユーザーから入力項目の意味を示す画面が提示された。これにより全13フィールドの対応と既存値の表示を確認した。支持力の1.2相当の差や、全勾配を同じ値にする理由は、この画面には示されていない。左右基礎を合わせた既存の全120周面支点で、6個のばね定数欄が同値、4個の制限値欄が同値であることも確認した。

前段の `test/..._土圧入力済み.ndu` は **SuppotNum=0** で、SuppotInfoレコード自体がない。後続の `fill_suppot_info.py` は、必要な周面支点レコードの新規追加とSuppotNum・SuppotRowの更新に対応し、追加修正で `Suppot_ChokuKisoCaseNo` の同期も行う。既存画面方式のprofileでは右周面60支点を追加し、杭先端支点は新規作成しない。SDCを正負・各勾配で個別反映する方式には上記の未確定事項が残る。
