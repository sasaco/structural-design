# 杭周面の節点ばね入力スクリプト

作成・レビュー日: 2026-09-17。

[`scripts/fill_suppot_info.py`](../../scripts/fill_suppot_info.py) はSDCの杭周面ばね・支持力を積分し、NDUの `SuppotInfo` に入力する。引数なしでは計算結果を表示する。`--output` で別名ファイルを出力し、入力原本は書き換えない。

## 対象と入力方式

2026-09-18、番号列形式に加えて奇数列・偶数列形式にも対応。既定の右SDCとグループ `--groups 4:1 5:2 6:3` は維持する。左SDC・対象NDU・`--groups 1:1 2:2 3:3` を明示すると、今町橋4Pの左基礎の周面60節点を処理する。表の2種類と実杭列数を区別し、元CSV欄を保持する。杭先端は別工程。

同日、`Ver.5.2.1` の杭列見出し省略形式にも限定対応した。d表第6欄の短期第1勾配K1と
e表第4欄の降伏点Fyを、方向内の実杭列2列または3列へ共有する。d表7欄・e表5欄、
完全な結合見出し、両表の有効長を検証し、原行・原欄を出典として保持する。
詳細は [対応計画と検証範囲](legacy-v521-sdc-support-plan.md)。

出力時は **`--profile existing-screen`** を明示する。この方式は、ユーザー提示画面と既存120周面支点で確認した「全勾配のばね値が同値、両制限値も同値」という配置を使う。

| 項目 | 使用する値 |
| --- | --- |
| 参照表 | 選択方向・押込み側のd表とe表 |
| 6個のばね定数欄（K1±、K2±、K3±） | d表の地震時または液状化時・第1勾配を節点区間で積分したK |
| 4個の制限値欄（F1±、F2±） | e表の降伏点（ρgfy考慮）を節点区間で積分したF |
| 支持力への追加係数 | なし。現在のSDC表示値を使い、1.2では割らない |
| 丸め | 合計後にROUND_HALF_UP。既定K=整数、F=小数1位 |
| 杭先端節点 | 既存支点を保持。新規作成・周面抵抗との合成はしない |

このprofileは**既存の数値を完全再現するものではない**。現在SDCと旧NDUの差は調査資料に記録済みで、補正係数を推測して合わせない。SDCの第2勾配・終局点を別々に使う方式や、引抜き表を別に反映する方式は実装対象外。

入力方式に関する確認への回答は、この作業中には「continue」の指示のみだったため、方式を確定した設計条件とはせず、明示的に選択するprofileとして実装した。引数なしの表示もこのprofileの計算例であり、全方式共通の答えではない。

## 計算と保存

`KGInfo` → `ElementInfo` → `JointXY` で杭と節点を取得する。節点番号の連番や部材番号との一致は仮定しない。鉛直で連続した杭を対象とする。

内部節点の負担区間は前後の節点との中点間。地層境界、1/βによる上端除外、杭先端の根入れ深さによる押込み側除外で区切る。

```text
ℓi = max(0, min(節点区間下端, 層有効下端) − max(節点区間上端, 層有効上端))
K = Σ(d表第1勾配[kN/m²] × ℓi[m])  → kN/m
F = Σ(e表降伏点[kN/m]  × ℓi[m])  → kN
```

区間長で割る平均処理はしない。表は固定行番号ではなく見出しで探し、単位・杭列・層番・層厚・有効長を検証する。d表とe表は地震時／液状化時の条件一致を要求する。d表だけは、先端除外で残存厚が0となる最終層について、層厚・⊿l・全ばね値がすべて0の場合に限って層厚0を許容する。e表の層厚は従来どおり正値必須である。

NDUへの配置:

```text
SuppotInfo番号= ,節点番号,2,K,F,F,K,F,F,K,K,K,K
```

- 対象のY支点があれば、第4～13フィールドを更新する。開始・終点・拘束方向、キー番号、改行を保持する。
- 対象のY支点がなければ末尾へ追加し、`SuppotNum` と `SuppotRow` を更新する。同じ項目番号の `Suppot_ChokuKisoCaseNo番号=0` も追加する。既存行の番号は変更しない。
- 他の拘束方向、対象外の支点、杭先端支点、地盤諸元などは保持する。
- 抵抗が0の節点には支点を新規作成しない。その区間に既存Y支点がある場合は、自動削除や微小ばね化をせずエラーにする。

**支点の増減時は、`SuppotInfo` と `Suppot_ChokuKisoCaseNo` の件数・末尾番号1～Nを必ず揃える。** 件数が変わらない更新でも欠落を0で補い、余剰0行を削除する。既存ケース値は保持し、重複・不正値・対応支点のない非0行は拒否する。削除・再採番時の対応維持を含む [共通編集ルール](suppot-info-editing-rules.md) を参照。

既定の元NDU `test/..._土圧入力済み.ndu` は支点数0なので、この入力からは右基礎の周面支点60件を追加する。**元データに存在しない左基礎支点や杭先端支点は追加しない**。既存126支点の `snap/...ndu` を入力にすると右周面60件だけを更新し、支点数126を保持する。

## 実行方法

PowerShellでリポジトリ直下から実行する。標準ライブラリだけを使い、同じフォルダーの `fill_jiban_shogen.py` に依存する。

### 計算確認

```powershell
.venv\Scripts\python.exe -B -X utf8 scripts\fill_suppot_info.py
```

既定SDCは `test/今町橋りょう4P(右).sdc`。SDCを明示する場合は `--sdc` を指定する。
`--sdc-direction longitudinal` で橋軸方向、`transverse` で直角方向を選ぶ。既定は `transverse`。

### 前段の土圧入力済みNDUへ追加する

```powershell
.venv\Scripts\python.exe -B -X utf8 scripts\fill_suppot_info.py `
  --profile existing-screen `
  --output "test\今町橋りょう4P(C方向･右押し→)_周面ばね入力済み.ndu" `
  --report ".agents\docs\suppot-info-fill-verification.json"
```

出力先は `.ndu` を指定する。入力ファイルとのパス衝突やハードリンク経由の同一ファイルは拒否する。異なる内容の既存出力は上書きせず、同じ結果の再実行は許容する。報告書も同じ扱い。

`--k-decimals` と `--force-decimals` は0～6を指定可能。これは書込み精度の設定であり、既存値との差を補正する係数ではない。

JSONには、採用profile、判定条件 `sdc_condition` / `sdc_condition_label`、参照SDC／NDUのSHA-256、節点ごとの重なり長さ・SDC行・丸め前K/F・第4～13フィールドの値、追加／更新件数、更新しない先端節点、出力のSHA-256を記録する。

## 対応しない入力

- 番号列形式と奇偶形式が曖昧に混在する表、奇偶形式で杭配置条件の実杭列数がない入力。
- 傾斜杭、突出長が0でない杭、杭長とSDC層厚が一致しない入力。
- 対象節点に重なるNDUの開始・終点による範囲指定、重複Y支点、複数の支点ケース。
- **先端節点の負担区間に押込み側の周面抵抗が残る入力。** 先端ばねとの合成が必要になるため、黙って切り捨てず処理を中止する。

## テスト・レビュー結果

以下は初回実装時の記録。2026-09-17の追加修正で `Suppot_ChokuKisoCaseNo` の同期を実装し、増減・欠落・既存値保持の回帰テストを追加した。検証範囲は [共通編集ルール](suppot-info-editing-rules.md) を参照。

[`tests/test_fill_suppot_info.py`](../../tests/test_fill_suppot_info.py) で計算・NDU出力・CLIを検証する。

```powershell
.venv\Scripts\python.exe -B -X utf8 -m unittest discover -s tests -q
```

確認内容:

- 全60支点のK/Fを、原SDCの表示値から `fractions.Fraction` で独立積分し一致。丸め後の120数値を照合した。
- 不連続な節点番号、上端除外、層をまたぐ区間、最終内部節点の短い有効長、最終段階の四捨五入を検証した。
- 支点0件からのNDU追加、既存NDUの部分更新、支点数変更を検証した。
- 現物NDUで、右基礎60支点を更新し、その他の支点・座標・部材・改行等が保持されることを確認した。
- 入力誤り、ケース数、節点重複、範囲指定、出力衝突、計算中の入力変更を拒否することを確認した。

実装後に作成者がコードとテストを再点検し、次を修正した。別エージェントによる独立レビューではない。

| 指摘 | 修正・検証 |
| --- | --- |
| 先端を一律にスキップすると、別の根入れ深さでは有効な周面抵抗を落とす | 先端の負担区間との重なりを検査し、合成が必要な入力を拒否。回帰テスト追加 |
| 出力前検査の後に同名ファイルが作られると、結果が異なっていても成功扱いになり得る | 排他的な新規作成を使用し、既存ファイルがあれば内容を再照合する。競合ファイルの保持をテスト |
| 節点移動で上端節点が抵抗区間に入ると、テスト中の配列位置が変わる | 期待する節点IDで検証行を選び直した。計算実装は変更不要だった |

対応profileの範囲では、レビューで見つかった実装上の問題は修正済み。SDCと旧NDUの設計条件差の解消、引抜き側・先端支持との合成、Input-JR/JRSNAPでの読込み・解析実行は今回の検証に含めない。入力用の恒久NDUはこの作業では作成しておらず、テストは一時ファイルで行った。
