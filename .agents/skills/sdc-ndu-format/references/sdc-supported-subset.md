# SDC supported subset

## Text and section rules

- ファイル全体を CP932 でデコードする。
- 見出しは完全一致または実装で列挙した別名だけを使う。
- セクション探索は次の見出しまでに限定する。別セクションの似た語を拾わない。
- 列番号は表の見出しから決める。値の大小や既存 NDU の値から列を推測しない。

## Direction, calculation case, and condition

既知の方向見出し:

- `（１）橋軸方向`
- `（２）直角方向`

地盤反力度の既知の計算ケース:

- `・応答変位法以外の場合`
- `・応答変位法の場合`

既知の条件識別子:

| Internal | SDC label family |
|---|---|
| `seismic` | 地震時 |
| `liquefaction` | 液状化時 |

同じ変換バッチで選択した水平ばね、反力度、周面支持、杭先端支持は同一条件でなければならない。条件混在は中止する。

## Column dialects

### Numbered columns

`1列目`、`2列目`、… のように各杭列を個別に示す。

### Parity columns

`奇数列` と `偶数列` の2系列を繰り返して杭列へ割り当てる。

### Pressure parity columns

地盤反力度では次の4系列を使う形式がある。

- `1列目`
- `2列目`
- `3列目以降奇数列`
- `4列目以降偶数列`

GUI で明示選択された列はそのまま使い、左右を理由に反転しない。旧 CLI の右側処理に限り、歴史的に列反転を行う実装があるため、呼出し経路を確認する。

### Ver.5.2.1 shared columns

正確なバージョン `Ver.5.2.1` と既知の表構造が両方一致する場合に限り、水平、周面、先端の
1組の値を方向内の実杭列2列または3列へ共有する。解釈名は `v5.2.1-shared`、
先端の省略見出しは `tip-v5.2.1-shared-omitted-headings`。同じ値を複製しても、出典は
原SDCの同じ行・CSV欄を保持する。バージョンだけではこの方言と判定しない。

### Pressure tail columns

Ver.5.2.1共有値形式の地盤反力度は `1列目`、`2列目`、`3列目以降` の3系列を使う。
実杭列2列では未使用の第3系列が上下とも0であることを要求する。実例のない1列と4列以上は拒否する。

### Pile-count aliases

杭列数・奥行き本数・影響長の既知見出しには、少なくとも次がある。

- `杭列数`
- `奥行き本数`
- 空欄セル
- `1/β(m)`
- `ｌ/β(m)`

空欄セルは既知の表構造内でのみ列として扱い、任意の空欄を意味付き見出しにしない。

## Supported data sections

| Operation | Main section / label | Parsed values |
|---|---|---|
| Horizontal spring | `b）設計水平地盤ばね値` | 深度区間ごとの水平ばね値 |
| Pressure | 地盤反力度表 | 深度境界ごとの反力度 |
| Shaft support | 周面ばね・摩擦力の表 | 深度区間ごとの K、正負の抵抗値 |
| Pile tip | 杭先端支持の表 | K1、K2、Fy、Fu |

深度は層境界または表の境界値として扱い、NDU の部材・節点座標との幾何関係を検証してから使用する。

## Liquefaction support status

液状化時対応はコミット `e9e3509` 時点で回帰テストがあるため `verified` とする。

- 水平ばね: `b）設計水平地盤ばね値` 内の `液状化時-` 系列を使う。
- 反力度: 液状化時の条件見出しを選び、末尾の余分な偶数個のゼロ対は許容する。
- 周面支持: ばね値と抵抗値で同じ条件を選ぶ。厚さゼロのばね行は最終行に限り、残り値がすべてゼロのときだけ許容する。
- 杭先端: 液状化時ラベルを選ぶ。K1 は正、K2・Fy・Fu は 0 以上、かつ Fu ≥ Fy とする。

上記条件を満たさないデータを「ほぼ同じ」として受理しない。

## Ver.5.2.1 shared support status

札幌駅P2橋脚・品川(東タ)道路P6の2 SDC × 2方向について、4処理、出典、Excel、既存NDU照合の
回帰テストが `f8ddd1f` でコミット済みのため `verified` とする。水平は4 NDUの全対象部材、
土圧は品川2 NDUの全対象部材と一致する。札幌の土圧および既存NDUの周面・先端合成欄は参照限定。
