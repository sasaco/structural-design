# 今町橋4Pモデルで確認した例

この資料はモデル固有の `observed` / `verified` 事実である。番号・座標・値を他モデルの既定値にしない。

右側3杭の杭先端節点は 122、147、172。既存データでこれらに対応した `SuppotInfo` は 124–126 だったが、支持項目番号は追加・削除の履歴に依存するため固定番号として使わない。

## Horizontal spring examples

- 部材98: 単一層の値 `58812`
- 部材99: 0.2 m と 1.1 m の層をまたぐ

```text
(58812 × 0.2 + 310863 × 1.1) / 1.3
  -> ROUND_HALF_UP
  -> 272086
```

## Pressure examples

- 部材98: 上端 `1162.9`、下端 `1307.5`
- 層境界をまたぐ部材99: 区間積分平均により上端・下端とも `1989.0`

## Shaft support example

右側3杭では、周面支持の対象節点が合計60節点になった実例がある。この件数は杭長、節点間隔、除外深度、根入れ、抵抗ゼロ区間に依存するため、一般的な期待件数にはしない。

## How to use this example

- 数式、列対応、参照連鎖の回帰例として使う。
- KG 番号や部材番号を他案件にコピーしない。
- 左右判定を杭長や節点番号だけで行わない。
- 現在の入力で同じ値にならない場合、まずモデル・SDC・列・条件が同一かを確認する。
